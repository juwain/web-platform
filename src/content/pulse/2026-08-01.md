## Новости

- [Декларативные частичные обновления HTML](https://developer.chrome.com/blog/declarative-partial-updates) — Барри Поллард и Ноам Розенталь предложили две идеи для веб-платформы: инструкции <?marker> и <?start>/<?end> в паре с <template> позволяют серверу вставлять HTML в нужные места без последовательной доставки. Плюс новые JS-методы setHTML(), appendHTML() и streamHTML() — единое API для частичных обновлений. Полифилы уже на npm.
- [CSS relative alpha](https://nerdy.dev/relative-alpha?utm_source=rss) — Новая функция alpha(from color / calc(alpha * .25)) в CSS Color Level 5 позволяет вычислять альфа-канал относительно другого цвета. Например, border-color: alpha(from hotpink / calc(alpha * .25)) — прозрачность на основе цвета источника.

### JS/TS

- [Как современный React думает о приоритетах](https://t.me/temaProg/134) — Тёма пересмотрел свой подход к объяснению React: вместо 60 FPS как отправной точки он теперь начинает с вопроса «что пользователь должен увидеть сразу, а что может подождать». Fiber — не только про скорость, но про то, какую работу делать в фоне, какую прервать, где показать старый экран. Хороший материал для mid+ разработчиков.
- [for await...of в JavaScript: практическое объяснение](https://t.me/cherkashindev/489) — Чёркашин разобрал for await...of на реальном примере: экспорт постов из Telegram в Astro-блог. Ключевой момент — цикл работает последовательно, а не параллельно. Идеально для пагинации и потоковой загрузки данных.

### CSS

- [CSS vs JavaScript: где реально проседает производительность](https://www.joshwcomeau.com/animation/css-vs-javascript/) — Josh Comeau сравнил CSS keyframes, чистый JS с requestAnimationFrame, Motion и GSAP на одном демо. Главный инсайт: JS-анимации тормозят не из-за вычислений, а потому что работают на main thread. Motion обходит это через Web Animations API. А в целом CSS стал достаточно мощным, что либы для анимации теперь нужны реже.
