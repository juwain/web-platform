### Статьи, мнения, туториалы

#### JS/TS

- [Composites: структурное сравнение объектов в JavaScript](https://frontendmasters.com/blog/arrays-objects-now-composites/) — Новая proposal — composites — даёт структурное сравнение для массивов и объектов. Два объекта с одинаковым содержимым, но разным порядком ключей — равны. Удобно для keying структурных значений в Maps и Sets.

#### CSS

- [flex-wrap: balance уже летит в Chrome](https://nerdy.dev/flex-wrap-balance) — Долгожданное `flex-wrap: balance` — свойство для автоматического выравнивания переполненных flex-контейнеров — официально движется в Chrome. Больше никаких хаков для красивых wrap-сеток.
