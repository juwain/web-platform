### Новости

- [Chrome 149: CSS gap decorations, crisp-edges, No-Vary-Search](https://developer.chrome.com/release-notes/149) — Новинки Chrome 149: CSS gap decorations рисуют линии между грид-элементами, image-rendering: crisp-edges для pixel-art, SVG path-length стал CSS-свойством. В 148 добавлен заголовок No-Vary-Search, чтобы UTM-параметры и ключевые-order не ломали HTTP-кеш.
- [Почему нативная рандомизация в CSS — это большой шаг](https://css-tricks.com/the-importance-of-native-randomness-in-css/) — CSS долго был детерминированным — случайность приходилось симулировать через селекторы или препроцессоры. Новые нативные функции random() наконец дают настоящую рандомизацию прямо в стеке браузера.

### Проекты

- [password-manager-react (Tauri v2 + Reatom v1000)](https://github.com/chromvoid/) — Менеджер паролей на Tauri v2 + Reatom v1000 + Lit с локальным RAG на Tree-sitter/Qdrant/BGE-M3. Несколько контейнеров с разными мастер-паролями, шифрованный канал для браузерного расширения, FUSE-том, встроенные медиа-плееры и Markdown-заметки. Пока Android, потом iOS/macOS/Linux/Windows.

### Статьи, мнения, туториалы

#### JS/TS

- [Navigation API Baseline](https://frontendmasters.com/blog/navigation-api-baseline/) — Navigation API стал baseline — единый NavigateEvent для любой навигации (клик, форма, back/forward, код). intercept() берёт на себя URL, историю, доступность и фокус. Вместо фрагментированного History API — одна точка входа.
- [Аккордеоны через CSS Grid без max-height](https://t.me/htmlshit/4109) — Классика — одна строка грида и 0fr ↔ 1fr. `grid-template-rows: 0fr` → `1fr` с transition даёт плавную анимацию раскрытия без костыля с max-height: 9999px. Дополнительно: grid-template-rows принимает minmax(), так что можно держать просвет свёрнутого аккордеона.
- [Скорость прототипирования в эпоху AI](https://darylcecile.net/notes/speed-of-prototyping-age-of-ai) — Инженер делится опытом: AI ускорил его работу примерно в 4 раза, количество рабочих прототипов выросло многократно. При этом он сознательно оставляет время на ручной кодинг, чтение исходников и дебаггер — чтобы не разучиться думать как инженер.
- [VK перешёл на SPA: скорость ×3.5, деплой за 20 секунд](https://habr.com/ru/companies/vk/news/1043220/) — VK перевёл веб-фронт на SPA и компонентный подход. Первая отрисовка ускорилась на 25%, среднее время перехода между разделами снизилось в 3.5 раза, время деплоя фронтенда сократилось до 20 секунд.
