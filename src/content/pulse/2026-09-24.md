## Новости

- [WebKit Features for Safari 27.0](https://webkit.org/blog/18325/webkit-features-for-safari-27-0/) — Apple выпустила Safari 27 с десятками новых веб-фич. Среди ключевых — улучшенная поддержка современных CSS-спецификаций, WebKit-оптимизации под macOS 27 и iOS 19. Браузерный релиз от платформы, на которую до сих пор многие ориентируются при разработке.
- [New in Edge for developers: create better components and make your site agent-ready](https://blogs.windows.com/msedgedev/2026/09/21/new-in-edge-for-developers-create-better-components-and-make-your-site-agent-ready/) — Microsoft Edge получил обновление с фокусом на улучшение веб-компонентов и поддержку AI-агентов. Edge теперь лучше информирует агентов о структуре сайта — новая реальность, где сайты должны быть «готовы к роботам», а не только к людям.

## Статьи, мнения, туториалы

### JS/TS

- [Astro React 7.0 — Replaces Babel with Oxc, upgrades to Vite Plugin React v6](https://docs.astro.build/en/guides/integrations-guide/react/#upgrading-the-react-integration-to-v700) — Интеграция React в Astro обновилась до 7.0. Babel ушёл в прошлое — теперь компиляция через Oxc, плюс поддержка Vite Plugin React v6. Ещё один ногтёк в крышку гроба медленных сборщиков.
- [Frontend for systems engineers](https://tj-zhang.com/blog/frontend-for-systems-engineers/) — Толковый разбор фронтенда глазами системного инженера — от TCP и TLS до рендера в браузере. Если вы когда-то чувствовали, что фронтенд «слишком простой» по сравнению с бэкендом, эта статья расставит точки над i в стеке технологий.

### CSS

- [12 CSS Features You Can Use Today with No Build Step](https://flaviocopes.com/modern-css-features/) — Подборка из 12 CSS-фич, которые работают прямо сейчас без транспиляции, PostCSS и прочих костылей. `light-dark()`, `attr()`, `@property`, container queries — нативная веб-платформа наконец дозрела.
- [CSS Scroll-Triggered Animations Are Here, And I Completely Missed Them](https://cydstumpel.nl/css-scroll-triggered-animations-are-here-and-i-completely-missed-them/) — CSS Scroll-Triggered Animations стали доступны в достаточном количестве браузеров, чтобы использовать их в продакшене. Никакого JavaScript для parallax и reveal-эффектов — чистый CSS с `animation-timeline: scroll()`.

### HTML/Accessibility

- [A Decent Custom Checkbox Pattern for Until ::checkmark is Ready](https://piccalil.li/blog/a-decent-custom-checkbox-for-until-checkmark-is-ready/) — Практичный паттерн кастомного чекбокса без взрыва accessibility. С `::checkmark` в спецификации всё ещё неясно, а формы стилизовать надо уже сегодня.

### Performance

- [The Root Scroller and How Not to Lose It](https://polypane.app/blog/the-root-scroller-and-how-not-to-lose-it/) — Почему `document.scrollingElement` иногда ведёт себя непредсказуемо и как не потерять root scroller на сложных layout'ах. Тонкости спецификации, о которых редко задумываются, пока не сломается inertia scrolling на мобилках.
- [Blurry Before Beautiful: Image Previews for the Web?](https://patrickbrosset.com/articles/2026-09-22-blurry-before-beautiful-image-previews-for-the-web/) — Патрик Броссе разбирает техники blur-up preview для изображений — от LQIP до нативных возможностей веб-платформы. Когда placeholder важнее самой картинки для perceived performance.
