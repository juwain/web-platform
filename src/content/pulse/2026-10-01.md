## Новости

- [Release Notes for Safari Technology Preview 253](https://webkit.org/blog/18357/release-notes-for-safari-technology-preview-253/) — Вышла сборка Safari Technology Preview 253 — свежие WebKit-фичи для ранних тестов. Загляните в release notes, что добавилось в движок и что можно пробовать уже сейчас.
- [Which Features Should Browsers Fix Together in 2027?](https://olliewilliams.xyz/blog/interop-and-beyond/) — Автор разбирает, какие веб-фичи браузерам стоит договориться поддержать совместно в Interop 2027: Sanitizer API с новыми HTML setter/streaming-методами, `moveBefore()`, transparency для VP9 и анимированного AVIF, CSS Link Parameters для стилей SVG, `focusgroup`, `box-decoration-break` без префикса и другие.
- [Preact 11](https://preactjs.com/blog/preact-11/) — Вышла долгожданная мажорка: Hydration 2.0 со стриминг-SSR, авто-forwarding refs, `Object.is` в зависимостях хуков, ESM-only и TS 5.1+. Все накопленные за шесть лет breaking changes наконец собрали в одну версию.
