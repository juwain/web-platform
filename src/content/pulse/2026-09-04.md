## Новости

- [Express.js security releases: six vulnerabilities across hbs, multer and morgan](https://expressjs.com/en/blog/2026-08-31-security-releases/) — Сразу шесть уязвимости нашли в популярных пакетах экосистемы Express — `hbs`, `multer` и `morgan`. Обновитесь, если используете любой из них.
- [Submit your ideas for Interop 2027](https://webkit.org/blog/18283/submit-your-ideas-for-interop-2027/) — WebKit открыл приём предложений для Interop 2027. Дедлайн 23 сентября. Основная идея: предлагайте только то, что уже имеет зрелый web standard и можно покрыть автоматическими тестами WPT.

## Проекты

- [NVM for Windows 2.0](https://docs.nvm-windows.com/features/newv2/) — Крупное обновление NVM для Windows — версия 2.0. Наконец-то адекватный менеджер версий Node на Windows без кривых скриптов и проблем с PATH.
- [Standard Schema](https://standardschema.dev/) — Универсальный интерфейс для валидационных библиотек — Zod, Valibot, ArkType и других смогут работать через единый API без vendor lock-in.

## Статьи, мнения, туториалы

### JS/TS

- [NestJS 12 Released with ESM-First Packages, Rspack and Vitest](https://trilon.io/blog/nestjs-12-is-now-available) — NestJS 12 перешёл на ESM-first packages, встроил Rspack и Vitest. Меньше конфигурации, быстрее сборка, особенно на больших проектах.
- [Bun 1.4 Now Passes 80% of Node's Test Suite](https://bun.com/node-test-suite) — Bun достиг 80% совместимости с официальным тестовым набором Node.js. Реализован `node:ffi` по умолчанию, улучшены `child_process` и другие низкоуровневые модули.
- [htmx 4.0](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released) — Крупный релиз htmx: запросы теперь через fetch, атрибуты больше не наследуются по умолчанию, встроен морфинг, новый тег для обновления нескольких целей. Carson Gross продолжает развивать серверный интерактив без JavaScript.
