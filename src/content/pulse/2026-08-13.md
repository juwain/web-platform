## Новости

- [Why tiny JPEGs look different in Chrome](https://guillaumetech.github.io/posts/jpg-scaling-chrome/) — Chrome рескейлит tiny JPEGs по-другому при определённых масштабах экрана — мелкий баг рендеринга, который ломает визуальную консистентность на некоторых устройствах.

## Статьи, мнения, туториалы

### CSS

- [Unlock immediate diagonal scrolling with CSS scroll-axis-lock: none](https://www.bram.us/2026/08/09/unlock-diagonal-scrolling-with-css-scroll-axis-lock-none/) — Новое свойство CSS scroll-axis-lock: none отключает браузерный «railing» — когда скролл автоматически блокируется по одной оси. Полезно для мап, зум-интерфейсов и диагональных панов. Поддержка: Chromium 153+.
- [Improved CSS text-stroke](https://tylersticka.com/journal/improved-css-text-stroke/) — Теперь paint-order: stroke fill позволяет рисовать обводку текста под буквоформами — больше никаких искажений legibility. Наконец-то поддержка во всех браузерах после добавления в Chromium.
- [The Windows Pipes screensaver built in CSS](https://css.graphics/pipes/) — Классический экран-заставку Windows NT Pipes воссоздали на чистом CSS — красиво как арт, но показывает возможности CSS-анимаций вне бьюти-полинга.

### Дизайн/Продукт

- [Dark mode toggles: two states are enough](https://lea.verou.me/blog/2026/dark-mode-toggles/) — Lea Verou аргументирует, что переключатель тёмной темы должен иметь два состояния (не три). Light/dark системный выбор избыточен — большинство людей либо любят тёмную тему, либо нет.
