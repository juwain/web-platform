## Новости

- [Kitesurf: Cloudflare's Browser Engine Now Open Source](https://blog.cloudflare.com/kitesurf-open-source/) — Cloudflare открыла исходный код своего браузерного движка Kitesurf. Полноценный рендерер, который компания использовала внутри собственных сервисов, теперь доступен всем. Движок заточен под headless-сценарии и edge-вычисления — возможно, именно так будет выглядеть следующее поколение инструментов для SSR и скрапинга.
- [How a Third-Party Script Turned Malicious on Major Sites](https://blog.report-uri.com/worlds-largest-brands-infected-with-malware-via-optimizely/) — Через платформу Optimizely Web 16 ноября зловредный JavaScript разошёлся по 178 организациям, включая Zoom, BBC, CNN, Salesforce, GitLab, IKEA и HSBC. Малварь подменяла адреса криптокошельков, собирала данные карт и на iOS доставляла эксплойт-киты. Всё началось с компрометации Project JavaScript в дашборде Optimizely — файл по-прежнему шёл с доверенного CDN, но содержал внедрённый загрузчик.

## Статьи, мнения, туториалы

### JS/TS

- [e18e's Ongoing Benchmarks of JavaScript Meta-Frameworks](https://e18e.dev/blog/launching-the-framework-performance-project/) — Состоялся запуск проекта Framework Performance от комьюнити e18e — постоянные бенчмарки мета-фреймворков (Next.js, Nuxt, SvelteKit, Astro, Solid Start и другие). Измеряют всё: от скорости установки зависимостей и размера node_modules до времени cold start dev-сервера и runtime-метрик. Каждый релиз фреймворка фиксируется, так что можно отслеживать прогресс во времени, а не просто сравнивать X и Y в один момент.

### WebAssembly

- [BrowserPod 4.0: A Linux-Like MicroVM for the Browser](https://browserpod.io/blog/browserpod-40/) — BrowserPod 4.0 — микро-ВМ на WebAssembly, которая работает прямо в браузере. Под капотом Linux-подобное ядро, написанное с нуля для веба, с поддержкой Node.js, Rust, git, bash, npm, pnpm. Процессы крутятся в Web Workers с единой виртуальной файловой системой. С версии 4.0 распространяется бесплатно для любого использования — без аккаунтов, ключей и телеметрии.
