## Статьи, мнения, туториалы

### JS/TS

- [VS Code уже пробует Go-based компилятор TypeScript 7](https://code.visualstudio.com/blogs/2026/06/26/iterating-faster-with-ts-7) — Новый Go-компилятор ускорил проверку типов с 36 секунд до 5 в VS Code. Microsoft тестирует его в раннем доступе — скорость выросла почти в семь раз без изменения API.
- [Неявный deadlock в Node.js: AsyncLocalStorage + worker_threads + await в run()](https://t.me/we_use_js/5398) — Скрещивание AsyncLocalStorage с пулом worker_threads и `await` внутри колбэка `run()` создаёт тихий deadlock. Воркеры заняты, потоки ждут — контекст ALS не отпускается до завершения. Решение: вынести ожидание наружу или передавать контекст через `postMessage()`.
- [[Next.js изнутри. Часть 5.] Серверный слой](https://telegra.ph/deep-dive-nextjs-part-5-06-27) — Разбор того, как запрос в Next.js проходит через серверный слой до рендера. Понятная карта маршрутизации, кэширования и обработки данных — для тех, кто хочет понимать фреймворк глубже уровня API routes.

### CSS
