## Проекты

- [tiks](https://rexa-developer.github.io/tiks/) — Процедуральные UI-звуки на чистом Web Audio API. 2KB gzipped, ноль зависимостей, семь типов звуков (click, success, error, hover и другие) и четыре темы — от мягких до аркадных. Идеально, если нужен звуковой фидбек в интерфейсах, но тянуть аудиофайлы не хочется.

## Статьи, мнения, туториалы

### JS/TS

- [Talk: React Server Components Vs. GraphQL](https://jordaneldredge.com/notes/rsc-vs-graphql) — Доклад с GraphQL Conf 2026, который строит общую ментальную модель для React Server Components и GraphQL. Автор разбирает, где RSC может полностью заменить GraphQL, а где имеет смысл использовать обе технологии вместе. Полезно, если вы выбираете между фетчингом через RSC и отдельным GraphQL-слоем.

### CSS

- [In-N-Out Animation using sibling-index()](https://master.dev/blog/in-n-out-animation-using-sibling-index/) — Temani Afif показывает, как анимировать добавление и удаление элементов без JavaScript, используя `sibling-index()` и `sibling-count()`. Когда DOM меняется, CSS сам пересчитывает позиции и делает плавный переход — без View Transitions и почти без JS. Пока работает только в Chrome/Edge, но это отличный пример того, куда движётся нативная анимация.
