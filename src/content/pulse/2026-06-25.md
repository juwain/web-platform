## Статьи, мнения, туториалы

### JS/TS

- [Гонки данных в AsyncLocalStorage при HTTP/2](https://t.me/we_use_js/5348) — AsyncLocalStorage привязан к async_hooks, которые изолируют одну цепочку асинхронных операций. При HTTP/2 мультиплексировании разные потоки попадают в один event-loop тик и перезаписывают данные друг друга. Каждый поток должен создавать свой Map, общий изменяемый объект внутри ALS — источник гонок.
- [WeakRef в EventEmitter вызывает GC-паузы до 5 секунд](https://t.me/we_use_js/5351) — В high-load Node.js приложениях подписки через WeakRef в горячем пути EventEmmitter создают pause-блокировки GC до 2–5 секунд. Долгоживущие объекты в old-space не собираются маркером из-за сокрытия за deref(). Решение — явно управлять подписками через on/off и избегать сильных ссылок на подписчиков.
- [Деоптимизация ESM: глубокий статический импорт vs Lazy Loading](https://t.me/we_use_js/5352) — Островная цепочка static import в ESM резолвит весь граф зависимостей синхронно перед выполнением кода, замедляя cold start на 30–50%. Динамический import помогает, но если модуль тащит свои статические зависимости — лаг просто переносится на первый запрос.

### CSS

- [Gap Decorations: новое CSS-свойство `rule` для декоративных линий между элементами](https://master.dev/blog/lets-play-with-gap-decorations/) — Temani Afif показывает возможности нового свойства `rule` (gap decorations): линии-разделители в зазорах grid/flex, fancy-подчёркивание через rule-inset, паттерны-сетки на всю страницу, repeat() для чередующихся толщин и цветов. Пока только Chrome/Edge.
- [Анимируем <dialog> через View Transitions API](https://pqina.nl/blog/animating-the-dialog-element-using-view-transitions/) — Rick Viscomi показывает прогрессивное улучшение: view-transition-name переносится внутри startViewTransition() с кнопки на диалог, создавая плавную трансформацию открытия модального окна. Проверяет prefers-reduced-motion для доступности.

### Performance

- [Когда вау-эффекты ломают гидратацию сайта документаций](https://t.me/alexnozer_dev/381) — SSR-сайт документации на VitePress стал полностью нечитаем из-за несоответствия гидратации — клиентское дерево не сошлось с серверным HTML, контент остался под opacity: 0. Избыточная реактивность добавила 262 КБ JS. Совет автора: SSG + точечный JS для виджетов вместо SPA-подхода.
