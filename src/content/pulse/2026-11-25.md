## Новости

- [Ladybird вышел в alpha](https://ladybird.org/posts/alpha/) — Новый браузерный движок, написанный с нуля, — теперь можно скачать на macOS и Linux без сборки из исходников. Пока alpha: будет падать и ломаться. Но проект уже проходит больше тестов WPT, чем Safari.

## Статьи, мнения, туториалы

### JS/TS

- [Web Dependencies are Broken. Can We Fix Them?](https://lea.verou.me/blog/2026/web-deps/) — Леа Веру о том, как npm + бандлеры превратились в обязательный шаг для любого JS-проекта — даже если нужна одна библиотека. import maps не спасают, а пересоздают бандлер в формате JSON.
- [Как мы удалили Moment.js, сначала сделав от него все зависимыми](https://medhat.dev/blog/removing-moment-js/) — Рассказ о миграции с Moment.js в большом TypeScript-монорепо: сначала обернули Moment в фасад, переписали 500 файлов без риска, а потом подменили движок под капотом. Минус 110 KB на каждой странице.

### Инструменты

- [webpack 5.113 — CSS Modules в HTML, SVG-оптимизация и ленивые лоадеры](https://webpack.js.org/blog/2026-11-19-webpack-5-113/) — Теперь можно писать style module прямо в HTML-шаблоне — webpack сам подставит скоупированные классы. Плюс встроенная минификация SVG, условный запуск лоадеров и улучшенное tree shaking для CommonJS.
- [webpack больше не нуждается в css-loader и html-webpack-plugin](https://webpack.js.org/blog/2026-11-16-css-and-html-are-built-in/) — С версии 5.109 CSS и HTML работают из коробки: импорт стилей разрешает аtimport и url(), module.css становится CSS Modules, HTML-страница может быть entry point. Миграция — через codemod.
