## Новости

- [React DevTools 8.0](https://github.com/react/react/blob/main/packages/react-devtools/CHANGELOG.md#800) — React DevTools 8.0: вкладка Suspense, панель React Element, удалён Timeline profiler в пользу Performance tracks, а поддеревья Activity теперь отображаются затемнёнными.
- [Chrome переходит на двухнедельный цикл релизов](https://techcrunch.com/2026/09/08/chrome-is-now-shipping-updates-every-2-weeks-as-ai-changes-the-security-landscape/) — Chrome теперь выходит каждые две недели вместо четырёх. Google ускоряет доставку security-патчей и новых фич в условиях, когда AI-генерация кода меняет угрозы безопасности.
- [Interop 2027: открыт приём предложений](https://blogs.windows.com/msedgedev/2026/09/03/calling-for-interop-2027-proposals/) — Приём предложений для Interop 2027 открыт до 23 сентября. Если есть идеи, как приблизить кросс-браузерную реализацию API — самое время формировать proposal.

- [The Best Dark Mode Toggle is Probably… None](https://lea.verou.me/blog/2026/dark-mode-toggles-2/) — Lea Verou аргументирует, что переключатель dark mode в интерфейсе — зачастую лишний элемент. Лучше полагаться на системную настройку prefers-color-scheme и не усложнять UI.
