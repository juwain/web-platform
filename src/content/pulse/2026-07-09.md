## Новости

- [Baseline Alerts в Web Platform Status](https://web.dev/blog/baseline-alerts) — В дэшборде Web Platform Status появилась система уведомлений, которая следит за статусом поддержки фич в браузерах и шлёт алерты, когда они переходят в Newly или Widely available. Подписка через GitHub, доставка в email, RSS или Slack — и да, поддерживаются персональные рассылки по сохранённым поискам.
- [FROST: атака на приватность через задержки SSD в браузере](https://hannesweissteiner.com/pdfs/frost.pdf) — Исследователи из Graz University of Technology показали, что сайт через Origin Private File System может отслеживать активность SSD по микрозадержкам чтения — и с точностью ~89% идентифицировать открытые сайты, ~96% — приложения. Google считает fingerprinting не уязвимостью, Mozilla признала проблему, но фикса пока нет.

## Статьи, мнения, туториалы

### JS/TS

- [Нужен ли здесь useEffect? 12 сценариев из React-код-ревью](https://habr.com/ru/articles/1055486/) — Разбор дюжины типичных ситуаций, в которых разработчики тянутся к `useEffect` по привычке, хотя эффект там не нужен. От производного состояния до React 19 — с конкретными примерами, когда хватит обычного вычисления или нового API.
- [И снова Infer: вывод типа первого аргумента функции](https://t.me/the_codebase/156) — Пошаговый разбор, как `infer` в TypeScript позволяет выводить тип первого аргумента произвольной функции. Трюк с rest-оператором и условными типами — лаконичный и покрывает большинство практических кейсов.

### CSS

- [CSS Linked Parameters](https://drafts.csswg.org/css-link-params-1/) — CSSWG выпустила ранний черновик спецификации, которая позволяет передавать параметры во внешние SVG-файлы прямо через URL или CSS `url()` / `link-parameters`. Цвета, толщины линий и другие свойства станут настраиваемыми даже для SVG, подключённых через `<img>`. Синтаксис ещё может измениться, но направление приятное.

### HTML/Accessibility

- [How to Make an Interactive Element Invisible but Accessible](https://master.dev/blog/how-to-make-an-interactive-element-invisible-but-accessible/) — Пара `hidden="until-found"` + `contain-intrinsic-size: auto none` позволяет прятать интерактивные элементы (skip-линки, кнопки копирования, anchor-ссылки) так, чтобы они оставались доступны для поиска по странице, фокуса и ховера — без layout shift. Хак из разряда «неочевидно, но пригодится».

### Performance

- [Chrome throttling: как DevTools замедляет ваш код и почему это важно](https://3perf.com/blog/chrome-throttling/) — Разбор того, как именно Chrome DevTools притормаживает JS и сеть при троттлинге, и почему результаты локальных замеров часто не соответствуют реальности на слабом железе или мобильных устройствах. Полезно для тех, кто всерьёз замеряет Core Web Vitals.
