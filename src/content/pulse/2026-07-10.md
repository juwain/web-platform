## Новости

- [TypeScript 7.0](https://t.me/front_everyday/1354) — Microsoft выпустила стабильную TypeScript 7.0 — компилятор переписан на Go, среднее ускорение сборки 8–12×. Strict включён по умолчанию, module: esnext — дефолт, старые флаги вроде target: es5 и moduleResolution: node теперь hard-error. Программного API пока нет, обещают в 7.1.
- [Bun переписывают на Rust](https://bun.com/blog/bun-in-rust) — Oven начала переписывать ядро Bun с Zig на Rust — PR уже влит в main. Пока неясно, как это отразится на производительности рантайма и совместимости, но масштаб изменений внушительный. Ждём подробностей.

## Статьи, мнения, туториалы

### JS/TS

- [Proxy and Reflect](https://piccalil.li/blog/proxy-and-reflect/?ref=main-rss-feed) — Mat Marquis разбирает, как Proxy позволяет перехватывать внутренние операции объекта — property access, assignment, вызовы — и зачем для этого нужен Reflect. Статья не про «как написать прокси», а про то, что происходит под капотом JS, когда вы читаете свойство.

### CSS

- [Thinking Horizontally in CSS @layer](https://master.dev/blog/thinking-horizontally-in-css-layer/) — Chris Coyier предлагает думать про @layer не как про вертикальный стек специфичности, а как про горизонтальные «слои» для компонентов. Если кастомные свойства каждого компонента класть в свой @layer, переопределения перестают быть битвой за специфичность.

### HTML/Accessibility

- [98% isn't very much](https://whynothugo.nl/journal/2026/07/03/98-isnt-very-much/) — Размышление о том, что 98% поддержки в браузерах — это всё ещё ~150 млн человек без доступа. И что для конкретной аудитории «широко поддерживаемая» фича может работать лишь у 70%. Не значит, что нельзя использовать новое, но аргумент «уже везде работает» стоит проверять по реальным метрикам.
