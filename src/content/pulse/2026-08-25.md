## Новости

- [Intent to Ship: JPEG XL](https://hacks.mozilla.org/2026/08/intent-to-ship-jpeg-xl/) — Mozilla объявила о намерении внедрить JPEG XL в Firefox — на основе безопасного декодера jxl-rs на Rust от Google Research. Chrome тоже намерен шипнуть, Safari уже частично поддерживает. Ключевые фичи: прогрессивный рендеринг (картинка появляется по мере загрузки), отличное сжатие без потерь и пережатие JPEG без потери качества. Выбор между AVIF и JPEG XL зависит от задачи: AVIF лучше для веб-фото, JPEG XL — для lossless и прогрессивного показа больших изображений.

## Статьи, мнения, туториалы

### CSS

- [Design Systems + Horizontal @layer](https://blog.master.dev/design-systems-horizontal-layer/) — Как масштабировать CSS `@layer` в больших дизайн-системах: вместо ручного описания компонентов можно прокинуть токены из пайплайна и управлять приоритетом стилей горизонтально. Дейв Руперт предлагает альтернативу — переопределение переменных через селектор `:defined`, не прибегая к `@layer`.

### Дизайн/Продукт

- [Every fork looks like adoption](https://blog.murphytrueman.com/every-fork-looks-like-adoption/) — Почему метрики adoption дизайн-систем обманывают: импорт компонента не означает reuse. Команды оборачивают Card в ProductCard, AI генерирует «похожий» код без импорта — и дашборд продолжает расти. Автор предлагает смотреть на изменение формы props, количество обёрток и структурную схожесть кода, а не только на счётчик импортов.
