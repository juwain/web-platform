## Статьи, мнения, туториалы

### CSS

- [Randomly Place an Element Along Edge of Another Element](https://blog.master.dev/randomly-place-an-element-along-edge-of-another-element/) — Трюк с `offset-path: border-box`, который позволяет заставить элемент гулять по границе родителя. Автор добавляет `random()` — и получается живой краб, который скользит по рамке в непредсказуемых точках. Изящное сочетание нового CSS-рандома и анимации без единой строки JS.

### Инструменты

- [Rendering Huge Pull Requests in the GitHub Copilot App](https://github.blog/engineering/user-experience/rendering-huge-pull-requests-in-the-github-copilot-app/) — GitHub перестроил рендер diff-ов в Copilot App, чтобы миллионные пулреквесты с сотнями inline-комментариев не убивали клиент. Под капотом — виртуализация, пулинг DOM-нод и переосмысленная синхронизация скролла. Практический разбор, как дотянуть производительность до уровня нативного редактора.

### Дизайн/Продукт

- [Props Are Not a Design System](https://vitonsky.net/blog/2026/09/18/design-system/) — Когда каждый компонент принимает `radius`, `size`, `color` и стену Tailwind-классов через пропы — получается не дизайн-система, а разрешённый хаос. Две одинаковые кнопки никогда не выглядят одинаково, потому что каждый разработчик подгоняет их под локальный контекст. Автор предлагает строгие токены и ограниченный API вместо бесконечной кастомизации.
