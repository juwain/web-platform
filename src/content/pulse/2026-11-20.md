## Новости

- [Express is now observable by design](https://expressjs.com/en/blog/2026-11-17-express-tracing-channels/) — Express наконец обзавёлся нативной observability: роутер теперь публикует события через TracingChannel, и APM-инструменты могут следить за middleware без monkey patching. Наконец-то можно забыть про require-in-the-middle и сломанные ESM-импорты — всё работает из коробки через Node diagnostics_channel.
- [OpenTelemetry JavaScript SDK 3.0](https://opentelemetry.io/blog/2026/otel-js-sdk-3-0/) — OpenTelemetry JS SDK 3.0 вышел с дропом Node 18/20, нормальными ESM-экспортами и стабилизацией Logs API. Мажор, но если вы используете zero-code instrumentation — ничего менять не нужно.

## Статьи, мнения, туториалы

### Performance

- [Load Testing an Express App on Node 26, Bun 1.4 and Deno 2.9](https://huseyinbabal.dev/posts/node-bun-deno-express-load-test/) — Прямое сравнение Express на Node 26, Bun 1.4 и Deno 2.9: Bun обогнал Node на 35–63% по throughput и жрёт вдвое меньше памяти. Deno, к сожалению, отстаёт даже от Node. Всё воспроизводимо из открытого репозитория.
- [Profiling a Node Site Build: Event Loop Utilization per Phase](https://marisstella.app/writing/the-idle-time-was-a-missing-cache/) — Автор профилировал сборку статики из 4500 страниц и выяснил, что половина idle-времени — это просто отсутствие кэша share-картинок. После включения кэша и трёх маленьких оптимизаций (async gzip, параллельный Python, фикс regex) сборка ускорилась на 4–5 секунд из 40.
