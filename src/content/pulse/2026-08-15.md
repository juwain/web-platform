## Новости

- [React Native 0.87 Released](https://reactnative.dev/blog/2026/08/11/react-native-0.87) — Главный релиз лета: Strict TypeScript API становится дефолтным JS API — типы генерируются прямо из исходников React Native, а deep imports в `Libraries/*` теперь ошибка компилятора. Metro 0.87 генерит sourcemaps в 2 раза быстрее и вдвое экономнее по памяти, на iOS появился экспериментальный Swift Package Manager вместо CocoaPods. Минимальный тулчейн поднят до Node 22.

## Статьи, мнения, туториалы

### JS/TS

- [A Tour of TanStack Form v2: Now in Alpha](https://tanstack.com/blog/announcing-tanstack-form-v2-alpha) — Библиотеку форм переписали с нуля после года сбора фидбека: валидаторы ушли от «объекта по событиям» к пайплайну, где каждый валидатор сам объявляет, какие триггеры его запускают. Плюс быстрее рантайм и безопаснее типы. Базовый синтаксис v1 не меняется — хороший момент заглянуть, если первая попытка не зашла.
- [Making Referential Stability a Type](https://www.jovidecroock.com/blog/referential-stability-types/) — Идея закодировать referential stability прямо в тип: брендовый `Stable<T>` через приватный `unique symbol` помечает массивы и колбэки, которые обязаны пережить посторонние рендеры. Тогда инлайн-выражение вроде `items.filter(...)` у мемоизированного компонента перестаёт быть невидимым — оно просто становится неправильным типом. useMemo/useCallback никуда не исчезают, но контракт стабильности ссылки становится проверяемым.
