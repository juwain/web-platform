## Статьи, мнения, туториалы

### JS/TS

- [TC39 Proposal: Iterator chunking](https://github.com/tc39/proposal-iterator-chunking) — Новое предложение в TC39: методы `chunk()` и `window()` для итераторов — разбиение последовательности на фрагменты фиксированного размера. Без промежуточных массивов, лениво, как всё в Iterator helpers.
- [Жмёшь кнопку — в ответ тишина. Как не профукать действие юзера и не наплодить дублей](https://habr.com/ru/articles/1084120/) — Что делать, если связь рвётся после тапа: API без toggle, ключ идемпотентности в PostgreSQL, очередь в IndexedDB, Service Worker и проверка офлайна в Playwright. Не полноценный offline-first, а страховка на момент обрыва.

### CSS

- [@codepen/slidevars](https://github.com/codepen/slideVars) — CodePen выложил утилиту для анимации CSS custom properties без `@property` — работает через Houdini и `transition-behavior: allow-discrete`. Полезно, когда нужно быстро поэкспериментировать с анимацией переменных.
- [prop-for-that](https://github.com/argyleink/prop-for-that) — Adam Argyle выпустил микро-библиотеку для декларативного управления CSS custom properties из HTML-атрибутов. Без JS-классов, чисто data-атрибуты → CSS переменные.

### Performance

- [Как ускорить сайт при блокировках](https://habr.com/ru/companies/itsumma/articles/1077670/) — Шесть практических мер для нестабильного интернета: перенос видео на доступные хостинги, сжатие и перевод в WebP/AVIF, lazy loading для картинок и тяжёлых блоков, проверка через Network в DevTools.
