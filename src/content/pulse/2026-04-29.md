### Новости

- [Rspack 2.0 — больше не просто «быстрый webpack»](https://rspack.rs/blog/announcing-2-0) — Rspack выходит за рамки webpack-совместимости: чистый ESM, нормальный tree-shaking для CommonJS destructuring и inline dynamic imports, persistent cache для SWC минификатора ещё на ~50% быстрее. Дев-сервер похудел с 192 npm-зависимостей до одной. npm-скачивания выросли со 100k до 5M в неделю — и это вполне заслуженно.
- [MDN полностью переписали — без React, на Web Components](https://developer.mozilla.org/en-US/blog/mdn-front-end-deep-dive/) — React был обёрткой поверх статического контента — они его выкинули и написали свой рендер-пайплайн на Lit Web Components. Результат: быстрее, проще, никакого hydration для контента, который не меняется. Самое MDN-шное решение из возможных.

### Статьи, мнения, туториалы

#### JS/TS

- [Что нужно знать в JavaScript в 2026 году](https://frontendmasters.com/blog/what-to-know-in-javascript-2026-edition/) — Chris Coyier нарисовал карту JS-ландшафта: ECMAScript 2025/2026, фреймворки, рантаймы, билд-тулы. Длинный и подробный обзор. Хорошо подходит как checkpoint — проверить, не упустил ли что-то за год.

#### CSS

- [CSS Containment — забытый инструмент для производительности](https://csswizardry.com/2026/04/what-is-css-containment-and-how-can-i-use-it/) — Harry Roberts разбирает CSS Containment с нуля. Фича доступна давно, но почти не используется. Позволяет браузеру пропускать пересчёт layout, paint и style для изолированных поддеревьев DOM. Как virtual DOM, но нативный и без JS. Если у вас есть виджеты или динамические блоки — containment может дать заметный прирост.
- [position:sticky теперь отслеживает ближайший scroll-контейнер по каждой оси](https://www.bram.us/2026/03/30/css-sticky-per-axis/) — Девятилетний баг в CSS-спецификации наконец исправлен: sticky-элементы могут независимо прилипать к разным scroll-контейнерам по горизонтали и вертикали. Лейауты, которые раньше были невозможны чистым CSS. Сначала landed в Chromium.

#### HTML/Accessibility

- [Ленивая загрузка видео и аудио стала веб-стандартом](https://engineering.squarespace.com/blog/2026/how-to-use-standard-html-video-and-audio-lazy-loading-on-the-web-today) — Chrome 148: нативный lazy loading для <video> и <audio> через loading="lazy". Firefox и WebKit на подходе. Никаких IntersectionObserver — работает как для изображений.
