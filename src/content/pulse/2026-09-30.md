## Новости

- [Cloudflare представил единый `cf` CLI для всех своих API](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) — Один CLI, закрывающий весь набор API Cloudflare: не нужно держать десяток отдельных инструментов — конфигурация, деплой и управление ресурсами сводятся в одну команду.
- [Vinext 1.0 — Next.js на базе Vite](https://blog.cloudflare.com/vinext-nextjs-on-vite/) — Cloudflare выкатил Vinext 1.0: портированная реализация Next.js, работающая на Vite вместо Webpack. Скорость сборки и dev-сервера заметно выше, при этом API остаётся знакомым.
- [EmDash 1.0 — стабильный «преемник WordPress» от Cloudflare](https://blog.cloudflare.com/emdash-cms-plugin-registry/) — EmDash достиг 1.0: статический генератор контента с плагин-регистром, позиционируемый как «successor» WordPress. Стабильный релиз означает, что систему можно брать в продакшн.
- [Четыре месяца VoidZero в Cloudflare](https://blog.cloudflare.com/voidzero-update/) — Команда VoidZero (компилятор Zig/JavaScript, из которого вырос Bun) подводит итоги четырёх месяцев работы в Cloudflare: что получилось, что осталось и куда движется компилятор.

## Статьи, мнения, туториалы

### JS/TS

- [Как GitHub улучшил performance, уйдя от CSS-in-JS](https://github.blog/engineering/architecture-optimization/improving-site-performance-by-shipping-more-css/) — Инженеры GitHub перенесли части интерфейса с CSS-in-JS на статический CSS и получили измеримый прирост скорости загрузки — хороший аргумент в вечном споре о runtime-стилях.
- [Оптимизация объектов через null-прототипы](https://adventures.nodeland.dev/archive/optimizing-objects-with-null-prototypes/) — Разбор, как объекты с пустым прототипом (`Object.create(null)`) быстрее обычных: меньше шагов в прототип-чейне, предсказуемая оптимизация V8. Полезно для горячих путей и кэшей.
