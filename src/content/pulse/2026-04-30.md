### Новости

- [Element-scoped View Transitions в Chrome 147](https://developer.chrome.com/blog/element-scoped-view-transitions) — Chrome 147 добавил element-scoped view transitions — теперь можно запускать переходы на конкретном контейнере, а не только на document. Позволяет анимировать список, не затрагивая сайдбар
- [TSRX — духовный наследник JSX](https://tsrx.dev/) — Dominic Gannaway (React, Svelte, Inferno) анонсировал TypeScript Render Expressions — компилятор, трансформирующий новый синтаксис в идиоматичный React, Solid или Ripple. Поддерживает условный рендеринг с хуками, SFC и async boundaries
- [Аналог.js 2.5 — runtime i18n, fast compilation и hierarchical content](https://dev.to/analogjs/analogjs-25-runtime-i18n-fast-compilation-mode-hierarchical-content-and-more-3ocj) — Вышла версия 2.5 метафреймворка Analog.js с runtime интернационализацией, режимом быстрой компиляции и поддержкой иерархического контента

### Проекты

- [Trees — библиотека рендеринга файловых деревьев](https://trees.software/) — Новая библиотека для рендеринга файловых деревьев от команды, работавшей над Preact и Wouter
- [Pracht — full-stack Preact-фреймворк](https://pracht.resynapse.dev/) — Новый full-stack фреймворк на базе Preact от Daishi Kato, автора React Server Components articles
- [GitButler — Git-клиент на стероидах](https://gitbutler.com/) — Скотт Чакон (сооснователь GitHub, автор Pro Git) привлёк $17M на GitButler — клиент с параллельными ветками, автосинхронизацией, автоматическими снимками и упрощённым управлением коммитами
- [Шакализатор сайтов 3000](https://github.com/Dark0ne1/shakal-3000) — Сервис превращает любой современный сайт в Web 1.0: вырезает стили и скрипты, добавляет кислотный фон, гифки и переписывает ссылки. Open-source

- [7 рецептов для View Transitions в CSS](https://css-tricks.com/7-view-transitions-recipes-to-try/) — Готовые шаблоны анимаций для плавных переходов между страницами — от dissolve до продвинутых эффектов с учётом prefers-reduced-motion
