## Новости

- [Introducing Firefox Enterprise](https://blog.mozilla.org/en/firefox/introducing-firefox-enterprise/) — Mozilla запустила Firefox Enterprise — версию браузера для организаций с self-hosted консолью управления. Цель — дать компаниям контроль над инфраструктурой и данными, избавляя от зависимости от Chrome/WebKit. Пока запускается в Европе: Германия, Франция, Австрия, Швейцария.

## Статьи, мнения, туториалы

### CSS

- [Fit height to background pattern size with calc-size()](https://ishadeed.com/article/fit-height-background-pattern-calc-size/) — Ахмад Шадид показывает, как `calc-size()` в связке с `round()` позволяет выровнять высоту блока под размер паттерна фона без обрезки. Вместо `background-repeat: round`, который деформирует изображение, CSS вычисляет auto-высоту и округляет её до кратного высоте плитки. Пока только Chrome, но трюк стоит в закладки.

### HTML/Accessibility

- [The Best Way to Use Icons in Web UIs](https://lea.verou.me/blog/2026/icons/) — Леа Вероу предлагает подход к иконкам, который полностью убирает inline SVG из HTML и переносит всё в CSS через маски и custom properties. Система позволяет задавать дефолтные иконки для компонентов и легко переопределять их без лишней разметки. Плюс выпустила пакет `@nudeui/icons`, где реализована вся механика.
- [TetraLogical Accessible Components Library](https://dbushell.com/notes/2026-10-15T05:15Z/) — TetraLogical выпустили библиотеку доступных компонентов с подробной документацией по критериям WCAG 2.2 — от уровня A до AAA. Для каждого компонента разобраны не только требования спецификации, но и usability в режимах высокой контрастности. Забирайте в референс, если верстаете tabs, accordion или формы.
