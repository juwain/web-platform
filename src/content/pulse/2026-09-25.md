## Статьи, мнения, туториалы

### JS/TS

- [Node.js Built-ins That Replaced npm Packages](https://flaviocopes.com/node-builtins/) — Flavio Copes собрал список встроенных модулей Node.js, которые вытеснили популярные npm-пакеты. От `util.parseArgs` до встроенного test runner — стандартная библиотека съедает зависимости один за другим.
- [made several libraries that ship in Node faster](https://lemire.me/blog/2026/09/22/a-summer-of-ai-optimization/) — Daniel Lemire рассказал, как за лето при помощи AI ускорил несколько библиотек, которые входят в состав Node.js. Речь про оптимизацию низкоуровневых операций, от которых выигрывает весь рантайм.
- [v18 adds a CLI](https://github.com/motdotla/dotenv) — dotenv 18.0 наконец обзавёлся встроенным CLI: `npx dotenv -e .env.local node script.js` — больше не нужен отдельный пакет для загрузки переменных окружения из командной строки.

### Инструменты

- [CVE Lite CLI: Scan Your Lockfile, Get the Upgrades to Run](https://owasp.github.io/cve-lite-cli/) — OWASP выпустил лёгкий CLI-инструмент для аудита lockfile. Запускаешь — получаешь готовый список команд для обновления уязвимых пакетов, без лишнего шума.
