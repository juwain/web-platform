## Статьи, мнения, туториалы

### CSS

- [Layout choreography: как анимировать изменения раскладки без телепорта](https://karlkoch.me/writing/on-layout-choreography) — Разбор подхода FLIP для плавной анимации изменений layout: запись bounding box до и после, инвертирование через transform, воспроизведение. Практический вариант на React + Motion с AnimatePresence и layout-пропом. Отдельно — про sequencing (что движется первым), scale-correction для детей и reduced-motion fallback.
- [Конические градиенты для треугольников: хитрость от Chris Coyier](https://master.dev/blog/when-you-need-to-make-a-triangle-think-conic-gradients/) — Chris Coyier научился видеть в `conic-gradient()` не просто круглые палитры, а способ рисовать треугольники и лучи из любого угла. Сдвигаешь origin в corner, ставишь жёсткие stop'ы на углах — и получаешь геометрические паттерны без SVG. На примере Studio Heyday видно, как это работает на реальном сайте.

### HTML/Accessibility

- [Доступное модальное окно на нативном `<dialog>` в Lit-компоненте](https://agustinbarrientos.com/writing/senior-eye/accessible-modal-dialog/) — Агустин Барриентос оборачивает нативный `<dialog>` в переиспользуемый Lit-компонент: `showModal()` даёт перехват фокуса и закрытие по Escape из коробки, `closedby` добавляет light-dismiss, `:open` + `@starting-style` анимируют появление, `prefers-reduced-motion` уважает accessibility.
