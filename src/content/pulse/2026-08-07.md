## Новости

- [Shai-Hulud Strikes Again, Affecting keyv and 400+ Packages](https://research.jfrog.com/post/shai-hulud-is-back-august/) — Обновление вредоносного supply-chain атакующего фреймворка Shai-Hulud затронуло keyv и ещё 400+ пакетов в npm. Исследователи из JFrog описали схему атаки, которая маскируется под легитимные зависимости.
- [Cloudflare Workers получили inbound TCP и gRPC](https://blog.cloudflare.com/grpc-workers/) — Cloudflare добавили поддержку входящих TCP-подключений и протокола gRPC прямо на платформе Workers — без дополнительных инстансов. Это значит, что теперь можно разворачивать gRPC-сервисы как serverless-функции.
- [Вышла Express security-release для body-parser](https://expressjs.com/en/blog/2026-07-31-security-releases/) — Express выпустили критические security-патчи для middleware body-parser. Если используете bodyParser в своих приложениях — стоит обновиться немедленно.

## Проекты

- [anydoc: конвертирование 14 форматов документов в Markdown](https://firecrawl.github.io/anydoc/) — Firecrawl выпустили любой формат документа в Markdown — PDF, DOCX, PPTX, HTML, Excel и другие. Подходит для AI-pipeline, где нужен унифицированный текстовый вход.
- [Flue 2.0 — фронтенд-фреймворк с type-safe роутингом](https://flueframework.com/blog/flue-2/) — Flue v2 выпущена с рефакторинг роутинга, улучшениями производительности и более чистым API. Фреймворк делает ставку на type-safety через TypeScript генерацию типов из файловых маршрутов.
- [GitHub Stacked PRs вышли в public preview](https://github.blog/changelog/2026-07-30-stacked-pull-requests-are-now-in-public-preview/) — GitHub перевели stacked pull requests из закрытого тестирования в public preview. Теперь можно связывать PR цепочкой, где каждый зависит от предыдущего — удобно для разбиения больших изменений.

## Статьи, мнения, туториалы

### JS/TS

- [Интеграционное тестирование Node-приложений с Testcontainers](https://flaviocopes.com/nodejs-testcontainers/) — Флавио Копес объяснил, как запускать базы данных и сервисы в Docker-контейнерах прямо из тестов Node.js — без мануальных setup скриптов. Конкретные примеры для PostgreSQL, Redis и MongoDB.
- [Архитектурные паттерны для Generative UI в React](https://boda.sh/blog/generative-ui/) — Разбор архитектуры генерации UI на лету — когда бэкенд возвращает не данные, а компоненты. Автор рассматривает паттерны для SSR-совместимых решений и безопасность рендеринга динамических компонентов.
- [React Arven: оптимизация Context для сложного локального стейта](https://granat.blog/posts/2026-07-24-react-arven/) — Библиотека-миксин, которая решает проблему избыточных re-renders при использовании React Context с глубокими деревьями состояний. Паттерн может заменить Zustand/Redux для умеренных приложений.

### Инструменты

- [Vite 8.2 — top-level input option и PostCSS config types](https://github.com/vitejs/vite/blob/v8.2.0/packages/vite/CHANGELOG.md#820-2026-07-30) — Новая Vite добавила top-level `input` опцию (минуя build.rolldownOptions), строгие типы для PostCSS конфигов и улучшенную обработку dev URLs.
