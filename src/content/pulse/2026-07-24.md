## Новости

- [Safari Technology Preview больше не выходит на macOS 15](https://dbushell.com/notes/2026-07-23T09:29Z/) — Apple тихо отключила STP для macOS 15 (Sequoia). ## Статьи, мнения, туториалы

### CSS

- [animation-composition: объединяй анимации без перезаписи](https://master.dev/blog/using-animation-composition-in-css-to-avoid-redeclaring-other-values/) — Новое свойство `animation-composition` позволяет комбини́ровать значения CSS-свойств из разных @keyframes без перезаписи. Например, одна анимация двигает элемент влево, другая — вниз, и с `animation-composition: add` обе работают вместе. То же для `box-shadow`: добавляешь новый тень поверх существующих без переобъявления всех.
- [FIFA турнирная таблица на чистых CSS-сабгридах (Ahmad Shadid)](https://ishadeed.com/article/fifa-layout/) — Ахмад Шадид пересобрал сетку чемпионата мира по футболу без обёрток-костылей. Чистый DOM: родительский grid задаёт колонки и строки, вложенные матчи через CSS-сабгриды наследуют дорожки, `grid-column: -2` для гибкого позиционирования, флексы центрируют матчи. Пример того, как правильно работает современный CSS-гейнинг.
