### Статьи, мнения, туториалы

#### JS/TS

- [Streaming HTML с Sanitizer API вместо HTMX](https://olliewilliams.xyz/blog/streaming-html/) — Ollie Williams показывает, как сделать свой лёгкий аналог HTMX: fetch → response.textStream().pipeTo() в элемент + Sanitizer API для безопасной вставки. Работает почти везде, кроме Safari. Красивый пример того, когда стоит собрать своё решение вместо использования чужого.
- [Web Audio API от создателя Web Audio Studio на JS Heroes](https://www.youtube.com/watch?v=Bnjxh_Z-CPY) — Anjana Vakil демонстрирует возможности браузера по генерации звука прямо в Web Audio Studio — от простых тонов до звуковых ландшафтов на основе погодных данных. Живой доклад с реальными демо, без воды.

#### Дизайн/Продукт

- [Coding Is Designing](https://blog.jim-nielsen.com/2026/code-is-design/) — Jim Nielsen пишет, что код — это не просто инструмент реализации дизайна, а сам инструмент поиска дизайна: меняешь X → видишь, как реагирует Y, подбираешь, пока элементы не лягут в цельное целое. Короткое, но точное наблюдение о процессе проектирования интерфейсов через код.
