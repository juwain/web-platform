## Статьи, мнения, туториалы

### JS/TS

- [Web Workers now have an experimental implementation in Node.js](https://nodejs.org/api/globals.html#class-worker) — Node.js получил экспериментальную реализацию Web Workers через `globalThis.Worker`. Позволяет запускать многопоточный код без `worker_threads` — используя нативный браузерный API.
- [How to Implement a Distributed Circuit Breaker](https://blog.gaborkoos.com/posts/2026-09-14-How-to-Implement-a-Distributed-Circuit-Breaker/) — Разбор паттерна Circuit Breaker для распределённых систем: когда стоит открывать/закрывать цепь, как считать пороги ошибок и зачем нужен полуоткрытый режим. Практический подход с примерами на TypeScript.

### CSS

- [Better Centering with CSS text-box](https://blog.master.dev/better-centering-with-css-text-box/) — CSS-свойство `text-box` решает вечную проблему неровных отступов внутри кнопок и бейджей. Без магических чисел — padding становится симметричным для любого шрифта, потому что вычисляется относительно текстового бокса, а не line-height.

### Инструменты

- [Why (and How) GitHub Ported Copilot's Runtime from Node to Rust](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/) — GitHub рассказывает, зачем они переписали рантайм Copilot с Node.js на Rust: уменьшение latency, снижение потребления памяти и использование Copilot-а самого себя для миграции кода. Кейс на границе инструментария и архитектуры.
