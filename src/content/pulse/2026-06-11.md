### Новости

- [npm v12 — дефолтные security-ограничения](https://github.blog/changelog/2026-06-09-upcoming-breaking-changes-for-npm-v12/) — Microsoft анонсировали npm v12 с радикальными изменениями: по умолчанию запрет на выполнение скриптов в зависимостях и дополнительные ограничения. Если где-то в лесу сдох рак — микромягкие всё же дошли до нормальных security-defaults.

### Проекты

- [performative-ui — визуализация прогресса сбора средств](https://vorpus.github.io/performativeUI/) — Компоненты, которые визуально показывают, насколько забита ваша раунд финансирования. Геймификация прогресса сбора средств прямо в UI стартапа.
- [Mitos — генератор ASCII-арта от Oxide Computer](https://mitos.shared.oxide.computer/) — Oxide Computer выложили в опенсорс Mitos — веб-инструмент для генерации ASCII-арта из изображений и гифок. Экспортирует текст, PNG или MP4. Выглядит реально круто.

### Статьи, мнения, туториалы

#### JS/TS

- [WebMCP — интерфейс для инструментальных вызовов ИИ из браузера](https://habr.com/ru/articles/1031164/) — Новый API `navigator.modelContext.registerTool` превращает сценарии подписки и других действий с сайта в быстрые вызовы функций, сокращая latency и стоимость по сравнению со скриншотным обходом. Прямой интерфейс взаимодействия браузера с AI-моделями.

#### CSS

- [Demystifying the View Transition Pseudo Tree](https://master.dev/blog/demystifying-the-view-transition-pseudo-tree/) — Подробный разбор внутреннего устройства View Transitions: как каждый псевдоэлемент участвует в анимации переходов между состояниями страницы и что происходит под капотом браузера.
- [Как оживить SVG-карту на чистом CSS](https://amberweinberg.com/css-animated-svg-maps/) — Эмбер Уэйнберг показывает, как оживить SVG-карту: ступенчатое появление меток через `transition` + `:nth-of-type`, проявление фона через `transform: translate3d()` и трюк со `stroke-dasharray/stroke-dashoffset` для рисования линий. Всё внутри prefers-reduced-motion.
