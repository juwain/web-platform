### JS/TS

- [cdnJS — 9 миллиардов запросов в день](https://blog.cloudflare.com/cdnjs-dev-platform-migration/) — Cloudflare делится историей миграции cdnJS — крупнейшего open source CDN, обрабатывающего 9 млрд запросов ежедневно. Как масштабировали инфраструктуру и решали проблемы совместимости.
- [Как microdiff работает так быстро](https://byteofdev.com/posts/microdiff/) — Разбор внутреннего устройства библиотек сравнения JavaScript объектов — что заставляет одни быть быстрее других в несколько раз. Глубокий анализ алгоритмов диффа.
- [Вау-эффект LLM не отменяет фундаментальные навыки разработчика](https://www.seangoedecke.com/llms-reward-expertise/) — LLMs reward expertise — большие языковые модели лучше работают с опытными инженерами. Краткий разбор того, почему техническая экспертиза становится ещё более ценной в эпоху ИИ.

### CSS

- [Gap decorations в CSS теперь доступны везде](https://css-tricks.com/css-gap-decorations-now-available/) — CSS gap decorations стали стабильными и поддерживаются во всех основных браузерах — рисуй декоративные линии между grid/flex дочерними элементами через свойство gap, без дополнительных обёрток или псевдоэлементов.
- [Новая единица измерения `lh` для типографики](https://ishadeed.com/article/lh-unit/) — Ахмад Шадид о новой CSS-единице `lh` — линейная высота привязана к font-size элемента и позволяет задавать максимальную ширину контейнеров точно в N строк текста. Идеально для prevent overflow на чистом CSS.

### Performance

- [Границы Core Web Vitals, которым вы доверяете, могут быть неверны](https://embrace.io/blog/research-core-web-vitals/) — Исследование показывает, что пороги Core Web Vitals (LCP, INP, CLS) могут не отражать реальное пользовательское восприятие. Когда metric passes, а юзер всё равно ждёт.
