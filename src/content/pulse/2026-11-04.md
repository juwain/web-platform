## Новости

- [Cloudflare Workers теперь поддерживает Temporal API нативно](https://developers.cloudflare.com/workers/configuration/compatibility-flags/#enable-the-temporal-api) — Cloudflare Workers получил нативную поддержку Temporal API — современного API для работы с датами и временем в JavaScript. Раньше разработчики полагались на полифиллы, теперь можно использовать Temporal прямо в Workers без флагов совместимости. Это важный шаг к стандартизации — Temporal давно обещали как замену кошмару Date.
- [Google и другие вендоры убирают XSLT из браузеров — execution date 17 ноября](https://dbushell.com/2026/11/03/xslt-rip/) — Google Chrome и другие Chromium-based браузеры лишатся поддержки XSLT уже 17 ноября. Двадцатилетняя технология трансформации XML уходит из веб-платформы, Google уже показывает предупреждения на сайтах с XSLT. Многие legacy-инструменты и RSS-ридеры лягут на бок.

## Статьи, мнения, туториалы

### JS/TS

- [npm считает пакет 'estee' опечаткой 'testem' и ломает CI](https://smoores.dev/post/no_npm_estee_is_not_a_typo/) — npm install отказывается устанавливать пакет estee, считая его опечаткой testem — и ломает CI-пайплайны, где этот пакет нужен. Автор разбирается, почему алгоритм Levenshtein distance в npm работает агрессивнее, чем должен, и почему это не просто неловкий баг. Хороший пример того, как UX-защита от дурака в инструментах разработки может обернуться проблемой.

### Performance

- [Microsoft: чистый код может хуже gzip'оваться](https://clarity.microsoft.com/blog/how-we-made-clarity-js-smaller/) — Команда Microsoft Clarity рассказала, как уменьшила размер своего JS-скрипта — paradoxically, более чистый код иногда сжимается хуже, чем запутанный. В статье разбирают техники оптимизации под gzip: дедупликация строк, предсказуемые паттерны и trade-off между читаемостью и сжатием. Полезно для всех, кто парится о Core Web Vitals и весе клиентского кода.
