### Новости

- [BCD Changes Report: 138 изменений за неделю](https://bcd-watch.igalia.com/weekly/2026-05-11.html) — Еженедельный отчёт Igalia: 138 изменений в Browser Compatibility Data. Из интересного — CSS container style queries с range syntax добавлены в Firefox, WebGPU createTexture descriptor поддержан всеми 3 движками, и множество обновлений по WebRTC и Web Audio API.

### Статьи, мнения, туториалы

#### CSS

- [The CSS Range Syntax — чище и понятнее media queries](https://ishadeed.com/article/range-syntax/) — Ahmad Shadeed разбирает range syntax в media queries: `@media (width >= 400px)` вместо `@media (min-width: 400px)`. Range-синтаксис устраняет частую ошибку с `min-width`/`max-width` когда значения не стыкуются, делает код читаемее. Поддерживается во всех браузерах.

#### HTML/Accessibility

- [Out With the JS, In With the HTML — Jim Nielsen](https://blog.jim-nielsen.com/2026/out-with-js-in-with-html/) — Jim Nielsen продолжает серию про «много маленьких HTML-страниц»: заменил web component для ресайза иконок на обычные HTML-страницы с разными URL (?size=sm/md/lg). Раньше — JS-компонент с кастомными атрибутами, теперь — навигация через View Transitions. Сайт полностью pre-rendered, и JS был единственным исключением — теперь его нет.

#### Инструменты

- [Avoid using CDATA in RSS — почему CDATA ломает фиды](https://waspdev.com/articles/2026-05-11/avoid-using-cdata-in-rss) — Разбор почему `<![CDATA[...]]>` в RSS/Atom — плохая практика: невозможно экранировать `]]>` внутри блока, ломается при вложенности, парсеры обрабатывают непредсказуемо. Альтернатива — XML-escaping (`&lt;`, `&amp;`) или Atom с namespace. Актуально для авторов RSS-фидов и разработчиков парсеров.
