## Статьи, мнения, туториалы

### JS/TS

- [Experiments with Multithreaded JavaScript](https://blog.arv.tools/archives/2026/11/02/18.35.20/) — Эксперименты с многопоточностью в JavaScript: автор исследует, как можно выжать параллелизм из языка, где основной инструмент — event loop и асинхронность.

### CSS

- [PropFLIP](https://nerdy.dev/prop-flip?utm_source=rss) — FLIP-анимации на чистом CSS: invert реализуется через 4 typed custom properties (`--tx`, `--ty`, `--sx`, `--sy`), а play — через CSS transition. Результат — прерываемые layout-переходы, где каждая ось имеет свой easing и delay, без постоянного пересчёта в JavaScript.

### HTML/Accessibility

- [Pardon my dust 2 – redesigning christianheilmann.com](https://christianheilmann.com/2026/11/10/pardon-my-dust-2-redesigning-christianheilmann-com/) — Christian Heilmann переписал личный блог с WordPress на статику: аккордеон через `details`/`summary` с атрибутом `name`, подсветка активной секции и затемнение остальных через `has()`, grid layout и dark/light версия. JavaScript используется только для поиска — всё остальное работает на нативных платформенных фичах.
