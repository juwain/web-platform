## Новости

- [Bun 1.4 получит поддержку React Compiler](https://github.com/oven-sh/bun/issues/24356#issuecomment-5276435139) — Bun 1.4 получит встроенную поддержку React Compiler. Runtime продолжает догонять Node по интеграции с экосистемой React — теперь и с компилятором, который оптимизирует мемоизацию автоматически.

## Проекты

- [Microlighter](https://daverupert.com/2026/08/microlighter/) — Микроскопический (~2 KB) синтаксический подсветчик на CSS Custom Highlights API. Zero dependencies, клиентский рендеринг без тяжёлых библиотек — подсветка через нативный браузерный API.
- [Poline](https://meodai.github.io/poline/) — Лёгкая TypeScript-утилита для генерации цветовых палитр через интерполяцию в полярных координатах. Без зависимостей, быстрая — рисует линии между anchor-точками и выдаёт гармоничные палитры.
