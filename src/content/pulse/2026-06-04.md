### Новости

- [Firefox экспериментирует с атрибутом headingoffset для заголовков](https://dbushell.com/notes/2026-06-03T13:45Z/) — Jake Archibald показал экспериментальную реализацию атрибута headingoffset в Firefox. Компонентный хедер больше не ломает иерархию страницы — уровень вычисляется динамически от родительского контейнера. Селектор :heading() стилизует по вычисленному уровню, а не по тегу. Планируется стандартизация.

### Проекты

- [heerich.js — 3D воксельные сцены в SVG](https://meodai.github.io/heerich/) — Минималистичный JS-движок строит объёмные воксельные композиции и рендерит их в чистый SVG. Boolean-операции (union, subtract, intersect, exclude), oblique/perspective камеры, decal'и с билинейной интерполяцией, hatch-паттерны — всё без зависимостей. Вдохновлён геометрией Эрвина Хериха.
- [Reatom JSX Gallery — кроссплатформенный просмотр фото из Reatom v1001](https://github.com/reatom/reatom/tree/v1001/examples/reatom-jsx-gallery) — Галерея для быстрого просмотра большого количества фотографий: рекурсивный обход папок, RAW, полный EXIF, выбор тем. Сборка ~60 КБ после gzipp — только Reatom в зависимостях. Отличный практический пример применения Reatom.

#### CSS

- [Obscuring Text with @counter-style](https://frontendmasters.com/blog/obscuring-text-with-counter-style/) — @counter-style работает не только для маркеров списков — его можно использовать для генерации псевдослучайных текстовых последовательностей. Маскировка данных (цифры карт, PIN-коды) через system symbolic, pad и positional algorithms. CSS-криптография в действии.

Линейки анимируются. Брехт Де Рюйте разбирает все нюансы.
- [Motion vocabulary — словарь паттернов анимаций](https://animations.dev/vocabulary) — Словарь из 50+ паттернов анимаций: entrances/exits, sequencing, transforms, scroll-driven, springs, easing, looping. Каждая единица с описанием и типичным применением. Справочник чтобы точно назвать нужный эффект при проектировании UI.

#### HTML/Accessibility
