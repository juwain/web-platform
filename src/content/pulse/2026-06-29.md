## Проекты

- [Web Platform Wishlist — Vale.Rocks](https://vale.rocks/posts/web-platform-wishlist) — Сборка реальных пожеланий к веб-платформе от практика: логические CSS-свойства для всего (translateInline, rotateInline), gradient easing, gradient shadows, native text overflow truncation from center, поддержка SVG-фильтров без perf-убийства, @supports без ложноположительных. Не wishlist разработчика фреймворка, а список фич, которые он реально хочет в каждом проекте.

## Статьи, мнения, туториалы

### JS/TS

- [Intelligence is Not Enough — Bryan Cantrill на Oxide](https://blog.jim-nielsen.com/2026/intelligence-isnt-enough/) — Jim Nielsen про talks от Bryan Cantrill об инженерных проблемах в Oxide: самые сложные баги лечились не интеллектом, а смекалкой, командой и упорством — решения, которые ИИ бы никогда не предложил, потому что они противоречат всем известным документам. Кейс за human values вместо cult of super intelligence.
- [By Humans, For Humans — Scott Riley](https://mindfuldesign.xyz/by-humans/) — Scott Riley пишет про шум вокруг AI и настоящие возможности для разработчиков за его пределами. Без прикрас — про пирамидальные схемы, брендированные тёплым оранжевым и transitional serifs, и про то, что мир возможностей всё ещё принадлежит людям.

### CSS

- [Animated radial gradient mask over text in CSS](https://cassidoo.co/post/radial-mask-text-css/) — Cassidy Williams сделала анимированную радужную маску поверх текста через mask + repeating-radial-gradient. Использует CSS Properties and Values API для анимации переменной ширины полос. Фактически маскирует текст прозрачностью, создавая эффект «кольц» вокруг букв.
- [Shifting line between CSS states and JavaScript events](https://css-tricks.com/css-states-and-javascript-events/) — Daniel Schwarz разбирает псевдоклассы CSS, которые всё больше работают как event-лислнеры: :hover, :active, :focus-visible, :has(), :checked. Также идёт proposal event-trigger из Animation Triggers spec. Главный вывод: CSS может обрабатывать состояния, для которых раньше требовался JS, но псевдоклассы остаются состояниями — не событиями.
