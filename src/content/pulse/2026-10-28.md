## Новости

- [The state of Deno after the Cloudflare announcement](https://github.com/denoland/deno/issues/37030#issuecomment-6310897867) — Deno Company официально перешла под крыло Cloudflare. Рантайм продолжат поддерживать до октября 2027 — примерно год багфиксов и security-патчей, но без новых фич. Старые и новые feature request останутся открытыми, а лишнее из canary свернут обратно к ветке 2.9.
- [Node2Shell (CVE-2026-111497) aka HTTP2Shell and Broccoli2Shell: RCE analysis](https://ellio.tech/en/blog/node2shell-cve-2026-111497-rce-on-stock-nodejs-builds/) — В Brotli-декодере Node.js нашли критический баг CVSS 9.2 — malformed compressed body позволяет выполнить произвольный код. Затронуты текущие LTS-ветки (22.x, 24.x, 26.x) и EOL-релизы. Уже появился сканер node2shell-check, который выявляет уязвимые серверы.

## Проекты

- [GTA.js, a reimplementation of the 1997 Grand Theft Auto engine in JavaScript and WebGL](https://www.bram.us/2026/10/22/gta-js/) — Брам ван Дамм переписал движок оригинальной GTA 1997 года на чистый JavaScript и WebGL — не эмуляция, а полноценная реализация с публичной документацией миссий. Проект частично написан с помощью Gemini, уже играбелен и доступен на gtajs.wtf.

## Статьи, мнения, туториалы

### JS/TS

- [Parser Combinators in TypeScript, Built From Scratch](https://t3.at/blog/parser-combinators/) — Автор строит библиотеку parser combinators с нуля на TypeScript и показывает, как парсить вывод ping в типизированный объект. Это middle ground между regex и tree-sitter — читаемый, композируемый подход, который легко держать в голове.
- [Tada after tsserver plugins](https://jovidecroock.com/blog/typescript-7-content-mappers/) — TypeScript 7.1 получил content mappers — внешние процессы, которые трансформируют не-TS файлы в TypeScript через JSON-RPC. Автор gql.tada уже реализовал mapper для CSS-модулей и GraphQL, и это может стать заменой tsserver plugins, которые пропали в TS 7 (Go port).
- [Objects, attributes, maps, oh my!](https://bernsteinbear.com/blog/object-shapes/) — Max Bernstein разбирает object shapes — технику оптимизации JS-движков, которая ускоряет доступ к полям за счёт inline caches. Статья с реальным кодом на Python и C++, которую можно прочитать и сразу понять механику за 500 строк.

### HTML/Accessibility

- [Building an Isolated Preview for AI-Generated HTML](https://blog.master.dev/building-an-isolated-preview-for-ai-generated-html/) — Рендерить AI-generated HTML в iframe без sandbox='allow-scripts' — значит дать ему доступ к parent.document и localStorage на вашем origin. Автор показывает три способа побега и правильную конфигурацию sandbox + CSP для безопасного превью.

### Инструменты

- [Biome v2.6—Support for new languages, JavaScript plugins, better Tailwind integration and the biome inspect command](https://biomejs.dev/blog/biome-v2-6/) — Biome 2.6 расширил поддержку языков — теперь есть Markdown, YAML и SCSS. Плюс JavaScript plugins в developer preview: пишем кастомные lint-правила на TS/JS, которые работают через Rust-движок boa. Ещё добавили команду biome inspect config.
