### Новости

- [Safari 26.5: :open, Origin API, SVG-улучшения](https://frontend-weekly.ru/weekly-digest-46/) — Apple обновила Safari — теперь есть :open для input-элементов, Origin API для проверки домена, доработки random() и улучшения SVG. WebKit продолжает догонять стандарты, особенно после заморозки разработки на год назад.

### Проекты

- [theSVG — 6030+ брендированных SVG-иконок](https://thesvg.org/) — Открытая библиотека SVG-иконок от известных брендов с npm-пакетом, React/Vue/Svelte компонентами, CLI, CDN и даже MCP-сервером. Если нужны качественные иконки Apple, Google или Notion — тут они есть.
- [Security in React Applications](https://telp.cc/1KSC) — Разбор типичных уязвимостей React-приложений: XSS, unsafe rendering, небезопасные паттерны аутентификации. Хороший чек-лист для code review.
