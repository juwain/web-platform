## Новости

- [npm now places a temporary 72-hour 'security hold'](https://github.blog/changelog/2026-09-09-npm-extends-recovery-code-security-holds-to-all-accounts/) — npm вводит 72-часовую "security hold" после входа через recovery code для всех аккаунтов: publish и создание токенов блокируются, чтобы замедлить захват аккаунта.

## Статьи, мнения, туториалы

### JS/TS

- [React Router 8.4](https://reactrouter.com/changelog#v840) — Релиз React Router 8.4: уменьшено количество лишних re-renders у Route-компонентов, а также появился более эффективный алгоритм route matching (пока под флагом unstable).
- [Modern Web Types: TypeScript Support for Newer Web APIs](https://philipwalton.com/articles/modern-web-types/) — Пакет modern-web-types от Philip Walton — drop-in замена DOM-типов TypeScript, собранная с порогом в один движок вместо двух. Добавляет 433 новых интерфейса DOM, 311 членов к существующим и 223 новых глобала.
- [A Design Space Exploration of async/await](https://cel.cs.brown.edu/blog/design-space-async-await/) — Исследование из Brown University показывает, что семантика async/await в разных языках (JS, Python, Rust, C#, Swift) расходится по девяти измерениям — от "eagerness" до способа отмены задач. Даже простейший fire-and-forget выдаёт четыре разных результата.
