## Новости

- [React Router v8](https://remix.run/blog/react-router-v8) — Вышла восьмая версия React Router — основной стабильный релиз с полным набором фич, который теперь стоит у руля всей экосистемы Remix. Если вы ещё на v6 с хаками для data loading, пора обновляться.
- [npm v12 Ships With Install Scripts Off by Default](https://github.blog/changelog/2026-07-08-npm-install-time-security-and-gat-bypass2fa-deprecation/) — npm 12 перестаёт исполнять install-скрипты по умолчанию — большое изменение безопасности. Теперь postinstall-эксплойты перестанут работать из коробки, а пакетам придётся явно запрашивать разрешение.
- [Vite+ Beta](https://voidzero.dev/posts/announcing-vite-plus-beta) — Команда Vite анонсировала Vite+ — платформу поверх Vite с managed деплоем, preview-окружениями и интеграцией CI. Пока в бете, но это попытка превратить сборщик в полноценный хостинг-провайдер.

## Статьи, мнения, туториалы

### JS/TS

- [Неявная блокировка Event Loop: как MapIterator убивает производительность в hot-path](https://t.me/we_use_js/5431) — Разбор скрытой проблемы V8: `for...of` по `Map` в hot-path может приводить к деоптимизации и аллокации `MapIterator` в куче, вызывая GC-лаг. Автор советует использовать `forEach` или кешировать ключи через `Array.from`.

### CSS

- [Get Ready for the CSS border-shape Property](https://css-tricks.com/get-ready-for-the-powerful-css-border-shape-property/) — CSS-Tricks разбирают новое свойство `border-shape`, которое позволяет задавать произвольную форму границы элемента без костылей с `clip-path` или SVG. Ещё одна ступень к тому, чтобы CSS мог рисовать произвольные формы нативно.
- [Playing with Infinity in CSS](https://codersblock.com/blog/playing-with-infinity-in-css/) — CSS теперь поддерживает `calc(infinity * 1px)` — и это не просто математическая шутка. С его помощью можно делать идеально скруглённые углы (`border-radius: calc(infinity * 1px)`) без вечной битвы с `9999px`.

### HTML/Accessibility

- [The Goldilocks customizable select height](https://jakearchibald.com/2026/goldilocks-select-height/) — Jake Archibald показывает, как довести нативный `<select>` до идеала с помощью небольшого CSS. Интерактивное демо для каждого улучшения — и видео для тех, чей браузер ещё не поддерживает все фичи.

### Дизайн/Продукт

- [What’s an Icon in 2026?](https://blog.jim-nielsen.com/2026/icons-as-software/) — Иконки перестали быть статичными картинками и превратились в мини-приложения. Apple теперь генерирует иконки на лету из слоёв, рецептов и эффектов — .icon-файл больше похож на документ с инструкцией, чем на PNG.
