### Статьи, мнения, туториалы

#### JS/TS

- [React под капотом: что изменилось за 4 года](https://t.me/temaProg/131) — Автор возвращается к старой лекции по React из ШРИ (92к просмотров) и показывает, что из классической модели Virtual DOM ещё что-то держится, а что уже слишком грубо. Основной сдвиг: React перестал быть просто библиотекой для описания UI и стал runtime, который управляет приоритетами. Батчинг, Suspense, Server Components, React Compiler — всё это не просто новые фичи, а новая философия планирования работы UI.

#### HTML/Accessibility

- [Baseline: container-style-queries, rlh, lh, user-activation](https://web-platform-dx.github.io/web-features-explorer/features/container-style-queries) — Web Features Explorer от Web Platform DX: container-style-queries вошли в Newly Available, а rlh, lh и user-activation — в Widely Available. Четыре веб-API, которые теперь стабильны и доступны в основных браузерах — пора переходить от экспериментов к продакшену.
