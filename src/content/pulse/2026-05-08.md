### Новости

- [Chrome 148: Prompt API на базе Gemini Nano](https://developer.chrome.com/docs/ai/prompt-api?hl=ru) — В Chrome 148 появился Prompt API — встроенный доступ к Gemini Nano прямо в браузере, оффлайн. Модель весит ~4 ГБ и подтягивается автоматически. Проблема: в каждом браузере своя модель, ответы непредсказуемы и могут меняться при обновлении. Сандартизация под вопросом.
- [Mozilla укрепляет Firefox с помощью Claude Mythos](https://hacks.mozilla.org/2026/05/behind-the-scenes-hardening-firefox/) — Mozilla описала, как с помощью Claude Mythos и agentic-харнесов нашла и исправила беспрецедентное количество уязвимостей в Firefox. AI-пайплайн для аудита безопасности: от поиска багов до триажа и шиппинга фиксов. Найдены sandbox-escape'ы, UAF и 20-летние баги в XSLT.
- [Safari Technology Preview 243](https://webkit.org/blog/17953/release-notes-for-safari-technology-preview-243/) — Много CSS-фиксов: `text-autospace` с ключевым словом `insert`, `contain: style` для счётчиков цитат, исправления `@scope` в web components, `:has(:empty)`, `position-area`, `clip-path: inset()` и ускорение `:where`/`:is`. Плюс фиксы accessibility для VoiceOver.

### Статьи, мнения, туториалы

#### JS/TS

- [Navigation API — замена History API для SPA](https://developer.mozilla.org/en-US/docs/Web/API/Navigation_API) — Navigation API решает проблемы History API единым событием `navigate` на `window.navigation`. Один обработчик вместо россыпи слушателей, `intercept()` вместо preventDefault, доступ к стеку через `entries()`, встроенная отмена через `signal`. Поддержка: Chrome 102+, Firefox 147+, Safari 26.2+.

#### CSS

- [safe-area-inset для мобильных раскладок](https://polypane.app/blog/using-safe-area-inset-to-build-mobile-safe-layouts/) — Разбор env(safe-area-inset-*) для учёта вырезов, камер и плавающих кнопок на мобильных. Зачем нужен `viewport-fit=cover`, как комбинировать отступы через `calc()`, и новые `safe-area-max-inset-*`, которые не меняются при скрытии адресной строки.

#### Инструменты

- [Bearnie — компонентная библиотека для Astro + Tailwind](https://bearnie.dev/) — Набор компонентов для Astro и Tailwind CSS, которые добавляются через CLI и остаются под вашим контролем. Быстрый старт: `npx bearnie init`. Можно расширять и собирать свою библиотеку поверх.
- [Griddy Icons — open-source иконочный шрифт](https://griddyicons.com/) — Бесплатная open-source библиотека иконок с утилитарным стилем. Более 1000 иконок, SVG-формат, подходит для веб-проектов.
