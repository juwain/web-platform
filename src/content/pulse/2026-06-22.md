## Новости

- [BCD Changes Report — RTCStatsReport, WebAssembly Suspending, WebDriver BiDi](https://bcd-watch.igalia.com/weekly/2026-06-22.html) — Еженедельный отчёт изменений в Browser Compatibility Data. Firefox получила полную поддержку RTC Stats API transport-статистики, WebAssembly Suspending API, WebDriver BiDi с поддержкой userContext для всех browsingContext событий, а также documentId повсюду в WebExtensions API.

## Проекты

- [Datatype — шрифт, который рисует графики из текста](https://franktisellano.github.io/datatype/) — Шрифт Datatype превращает текст в диаграммы прямо через CSS variable weight и stretch axes. Одна строка JSON-подобного текста рендерит bar chart, sparkline или pie chart. Поддерживает анимацию через JS.
- [Chrome AI API: перевод и детекция языка для Mastodon](https://youtube.com/watch?v=-l2BUUdBDS8) — Thomas Steiner показывает, как встроить машинный перевод в браузер с помощью нативных Chrome AI APIs — без внешних моделей. Демонстрация на примере поддержки мультиязычного общения в Mastodon.

## Статьи, мнения, туториалы

### HTML/Accessibility

- [You Don't Know HTML Lists](https://blog.frankmtaylor.com/2026/05/13/you-dont-know-html-lists/) — Глубокое исследование HTML-списков, выходящее далеко за рамки базовых ol/ul/li. Континуум списков, nested list types, ARIA roles для listbox/grid и множество тонкостей спецификации W3C, о которых забывают даже опытные разработчики.

### Performance

- [Когда нет утечки, а OOM приходит: дефрагментация кучи V8](https://t.me/we_use_js/5339) — OOM в долгоживущих Node.js-процессах при интенсивной работе с Buffer и стримами — не всегда утечка памяти. Old Space фрагментируется из-за живых объектов, блокирующих GC. Пулы буферов, stream.pipeline вместо ручного управления и monitoring через does_zap_garbage.
- [Скрытые убийцы Event Loop: ICU и Regex в Unicode-строках](https://t.me/we_use_js/5340) — String.normalize(), Intl API и regex с флагом /u могут блокировать Event Loop на десятки миллисекунд. Profiling через perf_hooks, вынос в Worker Threads и замена регулярных выражений на re2 — практические паттерны устранения.
