## Новости

- [tsrs: Cloudflare and VoidZero's Rust Port of TypeScript](https://blog.cloudflare.com/typescript-rust-port/) — Cloudflare и VoidZero вместе с Owner.com работают над tsrs — Rust-портом компилятора TypeScript. Ранние бенчмарки показывают до 8× прироста скорости и снижение потребления памяти на ~70% по сравнению с TypeScript 7.0.
- [Void, the Vite team's full-stack SDK and deploy platform, is now open source](https://blog.cloudflare.com/deploy-with-void/) — Команда разработчиков Vite выпустила Void в open source: SDK, CLI и платформа для full-stack приложений с file-based routing, pre-rendering, islands и end-to-end type safety. Deploy на Cloudflare работает из коробки: npm install void.

## Статьи, мнения, туториалы

### JS/TS

- [The Tetris Script That Becomes Snake Once Prettified?](https://trustsig.eu/blog/javascript-divergence/) — 186 техник divergence — багов в форматтерах, минифайерах и AST-принтерах, которые позволяют превратить один JS-скрипт в другой статически. Работает в 37+ инструментах: от prettier и babel до esbuild, swc, terser и Chromium DevTools. Демо: скрипт Tetris после форматирования запускает Snake.

### HTML/Accessibility

- [Do Web Components Have a Future If Nobody is Writing Them?](https://nolanlawson.com/2026/10/19/do-web-components-have-a-future-if-nobody-is-writing-them/) — Nolan Lawson, годами работавший над LWC и Web Components в Salesforce, признаёт: компоненты зашли в тупик. Он видит будущее в микро-фронтендах (изоляция команд без friendly fire), но констатирует, что производительность и DX всё ещё уступают React и Svelte.
- [State of Ecommerce Accessibility 2026](https://davedavies.dev/state-of-ecommerce-accessibility/) — Аудит 59 400 страниц товаров: 64% содержат хотя бы один critical accessibility failure, а 96% не проходят хотя бы одну автопроверку. В UK только из-за барьеров доступности ежегодно не происходит онлайн-покупок на £17 млрд — пользователи просто уходят к конкурентам.

### Инструменты

- [ESLint 10.13](https://eslint.org/blog/2026/10/eslint-v10.13.0-released/) — В no-use-before-define теперь учитываются IIFE при определении порядка использования, no-obj-calls научился ловить вызовы globalThis, а no-unsafe-optional-chaining проверяет аргументы yield*. Плюс фикс совместного автофикса no-var + one-var.
