#### JS/TS

- [AsyncLocalStorage в production: как не потерять traceId через очереди и connection pooling](https://t.me/we_use_js/5326) — Когда ALS работает хорошо (внутри await/promises), а когда — нужно явно фиксировать, передавать и восстанавливать traceId через очереди, scheduler'ы и connection pooling.
- [Graceful shutdown в Kubernetes: почему одного SIGTERM мало](https://t.me/we_use_js/5327) — Staged shutdown для Node.js: draining → /readyz отдаёт 503 → closeIdleConnections → GOAWAY для HTTP/2 → дождаться задач. Одного server.close() недостаточно.
- [Deprecating a React component using TypeScript Overload](https://dev.to/mbarzeev/deprecating-a-react-component-using-typescript-overload-2ka) — IDE показывает зачёркивание для старого usage, подталкивая к миграции без создания ComponentNameV2. Компонент принимает оба интерфейса и пробрасывает вызов.
