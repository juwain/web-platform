## Новости

- [Why There Are Still No Non-WebKit Browsers on iOS](https://blog.mozilla.org/en/mozilla/internet-policy/apple-ios-browser-engine-rules/) — Mozilla в деталях объясняет, почему спустя три года после DMA и год после аналогичных правил в Японии на iOS до сих пор нет ни одного браузера на стороннем движке. Условия Apple остаются неработоспособными: чтобы завезти Gecko, придётся собирать второй Firefox.
- [Compression Dictionary Transport](https://csswizardry.com/2026/11/web-perf-wednesday-019-firefox-ships-dictionary-compression/#firefox-ships-compression-dictionary-transport) — Firefox 161 поставляет Compression Dictionary Transport. Если браузер уже имеет версию ресурса, сервер может использовать её как словарь и отправлять только diff. В тестах бандл YouTube player оказался на 90% меньше обычного Brotli.

## Статьи, мнения, туториалы

### CSS

- [Motion Design with CSS Anchors](https://blog.master.dev/motion-design-with-css-anchors/) — CSS anchor positioning обычно используют, чтобы привязать элемент к якорю. Но если переключать якорь и анимировать переход между ними, получаются эффекты движения по точкам маршрута — и всё на чистом CSS, без отслеживания координат вручную.

### HTML/Accessibility

- [A New Set of HTML Insertion and Streaming APIs](https://www.amitmerchant.com/javascript-gets-a-new-set-of-html-insertion-apis/) — Chrome и Edge получили новый набор методов для вставки HTML: `appendHTML()`, `prependHTML()`, `beforeHTML()`, `afterHTML()`, `replaceWithHTML()`. Имена сразу говорят, что происходит с контентом — прощай, непонятные строки `insertAdjacentHTML()`. Есть и API для стриминга HTML прямо в DOM.

### Performance

- [Has the Web Stopped Getting Heavier?](https://www.iron-out.io/blog/has-the-web-stopped-getting-heavier/) — Анализ HTTP Archive показал: медианная мобильная страница набрала всего 7 КБ JS за год после роста в 70 КБ/год ранее. Пик был в апреле (717 КБ), сейчас 690 КБ. Но самые тяжёлые 10% сайтов продолжают расти.
