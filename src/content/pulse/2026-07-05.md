## Проекты

- [Web Audio Studio — апдейт визуализаций](https://app.webaudio.studio/) — Масштабный апдейт визуализаций в интерактивном редакторе Web Audio API — инспекция точек на графиках BiquadFilterNode и IIRFilterNode, градиентный спектр в AnalyserNode, стабильный осциллограф с подсветкой клиппинга и точечные tooltip'ы по частоте, dB, времени и амплитуде.

## Статьи, мнения, туториалы

### JS/TS

- [Диагностика гонок данных в node:sqlite из worker_threads](https://t.me/we_use_js/5394) — Как бороться с `SQLITE_BUSY` при конкурентном доступе к `node:sqlite` из `worker_threads`: `DatabaseSync`, `PRAGMA journal_mode=WAL`, `BEGIN IMMEDIATE` и координация через `SharedArrayBuffer`. Автор предупреждает — in-memory WAL теряет данные при краше, для продакшена нужна файловая база.

### CSS

- [text-fit](https://shabalin.online/blog/css/text-fit/) — Новое CSS-свойство `text-fit`, реализованное пока только в Chrome 150 (desktop), автоматически подгоняет размер шрифта под ширину блока — без JS и без `clamp`-хаков. Живая типографика в одной строке CSS.
