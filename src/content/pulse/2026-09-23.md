## Новости

- [stage-only tokens](https://github.blog/changelog/2026-09-18-stage-only-npm-tokens-for-safer-automation/) — GitHub ввёл stage-only npm tokens для безопасной автоматизации публикации пакетов. Токен позволяет заливать артефакты только в staging-репозиторий, что снижает риски случайной публикации в прод через CI.
- [ESLint 10.11.0](https://eslint.org/blog/2026/09/eslint-v10.11.0-released/) — Релиз ESLint 10.11.0 с обычным набором улучшений и фиксов. Как всегда, обновляйтесь для свежих правил и стабильности.

## Проекты

- [Electrobun](https://blackboard.sh/electrobun/) — Electrobun — фреймворк для создания desktop-приложений на веб-стеке с Bun внутри. Альтернатива Electron для тех, кто хочет что-то легче.
- [Plotly.js 4: A Big Update for the Popular Charting Library](https://plotly.com/blog/announcing-plotly-js-4-plotly-py-7/) — Plotly.js 4 вышел с серьёзным обновлением рендера и новыми типами визуализаций. Популярная библиотека для интерактивных графиков продолжает развиваться.
