## Новости

- [Chrome Web Store removes all remaining Manifest V2 extensions](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) — Google добил всех: из Chrome Web Store убрали последние MV2-расширения. Ублочки и всё, что не успело портировать на MV3, теперь не найти в официальном магазине.
- [Firefox for iOS: built-in opt-in ad blocker](https://blog.mozilla.org/en/firefox/ad-blocker-on-ios/) — Mozilla встроила опциональный адблок в Firefox для iOS — без сторонних расширений. Для мобильного Firefox это крупный шаг к конкуренции с Safari.

## Статьи, мнения, туториалы

### CSS

- [Controlling When CSS Custom Properties Are Computed](https://jakearchibald.com/2026/css-custom-property-compute-time/) — Jake Archibald разбирает механику вычисления кастомных свойств CSS: когда именно браузер разрешает `var()`, как это влияет на `@media`, переопределения и наследование. Полезно, если вы когда-нибудь ловили странные баги с `var()` в разных контекстах.

### Performance

- [Speedlify2: Continuously Measure Website Performance](https://www.zachleat.com/web/speedlify2/) — Zach Leat (автор WebPageTest-статей и PerfGuardian) представил Speedlify2 — инструмент для непрерывного мониторинга производительности сайта. Не разовый запуск Lighthouse, а постоянный RUM-сигнал по ключевым метрикам.
