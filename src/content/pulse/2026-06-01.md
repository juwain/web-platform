### Новости

- [Jest 30.4.0](https://github.com/jestjs/jest/releases/tag/v30.4.0) — Крупный релиз Jest. Переписан заново собственный рантайм в preparation для нативной поддержки ESM — теперь require(esm) работает на Node 24.9+. Fake timers наконец-то понимают Temporal API (Duration, Instant, ZonedDateTime). Поддержка React 19 в pretty-format: snapshot'ы теперь рендерятся корректно. Новый флаг --collect-tests для discovery тестов без запуска, поддержка jest.config.mts.
- [pnpm 11.1](https://github.com/pnpm/pnpm/releases/tag/v11.1.0) — Первый мажорный апдейт после pnpm 11: audit signatures для ECDSA-проверки registry, поддержка установки пакетов из GitHub Packages через gh: префикс, алиасы named registries в pnpm-workspace.yaml и новые флаги для CI. Безопасность на уровне рантайма.
