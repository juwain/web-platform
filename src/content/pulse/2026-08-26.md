## Новости

- [ESLint 10.9](https://eslint.org/blog/2026/08/eslint-v10.9.0-released/) — Вышел патч-релиз 10.9.1: докрутка прошлой версии и починка нескольких багов. Новых фич нет — просто стабильнее.

## Проекты

- [Formisch 1.0 — фреймворк-агностичная библиотека форм](https://formisch.dev/blog/formisch-v1/) — Formisch вышла в стабильную 1.0: библиотека форм вокруг схем — схема задаёт типы и валидацию, UI собирается поверх на любом из 8 фреймворков. Логика форм не меняется при смене фреймворка, миграционные гайды есть для шести из них.

## Статьи, мнения, туториалы

### JS/TS

- [Защита от waterfall-запросов в Server Components через React 19 cache()](https://aurorascharff.no/posts/avoiding-server-component-waterfall-fetching-with-react-19-cache/) — Толковый разбор API `cache()` из React 19 в Next.js App Router: как мемоизировать повторные запросы за один серверный рендер, не поднимая fetch на верх и не связывая компоненты. Бонус — паттерн предзагрузки данных, который убирает каскадные запросы в RSC.

### Инструменты

- [React Compiler linting — нативное ускорение на Rust в Oxlint](https://blog.master.dev/react-compiler-linting-just-got-a-rust-native-speedup-in-oxlint/) — Oxlint теперь умеет нативно на Rust линтить код под React Compiler — это было главным тормозом сборки. На примере миграции всего тулчейна (eslint → Oxlint, prettier → oxfmt, jest → vitest, Rollup → Rolldown) автор показывает, что с Rust-переписанным React Compiler весь цикл сборки почти мгновенный.
