## Новости

- [Safari Introduces Adaptive Dark Mode](https://webkit.org/blog/18541/introducing-adaptive-dark-mode/) — В Safari 27.3 beta появился Adaptive Dark Mode — браузер будет автоматически переводить светлые сайты в тёмный режим. Идея в том, что почти 40% загрузок страниц приходится на пользователей с тёмной темой, но лишь 10% сайтов её поддерживают. Safari анализирует цвета страницы и инвертирует их через специальную матрицу, сохраняя оттенки. При этом сайты не смогут детектировать режим — это решение Apple в пользу приватности.

## Статьи, мнения, туториалы

### CSS

- [Modern CSS Might Make Your Front-End More Complex](https://www.smashingmagazine.com/2026/11/modern-css-might-make-your-front-end-more-complex/) — Стоит ли заменять JS на современный CSS, если это уменьшает количество кода в одном файле, но размазывает логику между слоями? Автор Smashing Magazine разбирает, как контейнерные запросы и другие CSS-фичи иногда делают более сложной отладку всей системы. Локальная простота ≠ простота на уровне проекта.
- [Native Masonry Layouts with CSS Grid Lanes](https://piccalil.li/blog/native-masonry-layouts-with-css-grid-lanes/) — Нативная masonry наконец-то обрела форму: `display: grid-lanes` — новый layout mode в CSS, который позволяет располагать элементы по рядам, заполняя колонки по мере свободного места. Статья Piccalilli подробно разбирает синтаксис и объясняет, почему спецификация шла так долго.

### Performance

- [How a Split Webfont Slowed Down Text Layout](https://www.ivankristianto.com/split-webfont-text-layout/) — Разбиение шрифта на сегменты с `unicode-range` может выстрелить в INP. Если соседние буквы одного слова оказываются в разных файлах, браузер вынужден делать layout в несколько проходов. На практике это повышало INP на мобильных страницах выше 200 мс.
