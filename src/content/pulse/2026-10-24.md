## Новости

- [WebKit Features for Safari 27.1](https://webkit.org/blog/18486/webkit-features-for-safari-27-1/) — Safari 27.1 доступен на iPhone Duo — главное для разработчиков это превью Device Posture API и Viewport Segments API за флагами, а также автоматический двухстраничный просмотр PDF на сложенном экране.
- [TypeScript 7.1 is now in beta](https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/) — Бета TypeScript 7.1 с поддержкой import attributes в ambient declarations, source phase imports и target es2026 с методами вроде Math.sumPrecise() и Iterator.concat(). Отдельно выделили новую модульную compiler API и content mappers для нативной интеграции Vue, Svelte, Astro.

## Статьи, мнения, туториалы

### JS/TS

- [The Vertical Codebase](https://blog.master.dev/the-vertical-codebase/) — Dominik из tkDodo предлагает «вертикальный кодбейз»: группировать весь код (хуки, типы, запросы) по концептуальным областям вместо разброса по hooks/, types/, queries/.

### Performance

- [Fast is a design decision](https://shannadige.com/blog/performance-is-design/) — Автор доказывает, что производительность — design decision, а не задача «потом оптимизируем». Дешево накрутить анимаций, но пользователи платят временем загрузки, а дизайнеры потом уже не в проекте.
