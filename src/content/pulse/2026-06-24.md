## Новости

- [Astro 7.0 — релиз со свежим Rust-компилятором и полным доступом к request pipeline](https://astro.build/blog/astro-7/) — Major Vite upgrade, shiny new Rust-based build compiler, and unblocked access to the full request pipeline. Если ваш workflow трогает middleware или data-fetch hooks — это меняет правила.
- [Vite 8.1 — «full bundle mode» для разработки](https://vite.dev/blog/announcing-vite8-1) — Экспериментальный bundled dev mode: сервер отдаёт один цельный бандл вместо HMR-разбивки. Снижает количество запросов и приближает dev-среду к production-поведению.
- [Polygraph от Nx — meta-harness для ИИ-агентов поверх полирепозиториев](https://trypolygraph.com/) — Jeff Cross и команда Nx выпустили Polygraph: строит dependency graph из всех репозиториев организации и подаёт его агентам как synthetic monorepo контекст. Агенты читают, пишут и grep'ят через репо-границы без потери session context.

## Статьи, мнения, туториалы

### JS/TS

- [cnfast — замена tailwind-merge и clsx до 7x быстрее](https://github.com/aidenybai/cnfast) — Aiden Bai пушил быструю замену для конкатенации CSS-классов. Заявлено до 7x относительно clsx. В проектах с тысячами ререндеров разница может быть заметна на клиенте.
- [ast-grep outline: агенты читают структуру файла без полного парсинга](https://ast-grep.github.io/blog/ast-grep-outline.html) — Команда ast-grep добавила outlining — можно запросить лишь структуру (функции, классы, экспорты) без полной синтаксической расшифровки. Экономит токены при работе с большими файлами для агентов.
- [TanStack Table v9: сокращение памяти на 90% для больших таблиц](https://tanstack.com/blog/tanstack-table-v9-memory-performance) — Kevin Van Cott описал как команда вырезала 90% потребления памяти в v9. Для таблиц с десятками тысяч строк — разница между лагами и плавностью, особенно на слабых устройствах.
- [inbrowser-agent: полный AI-стейк включая inference прямо в браузере](https://github.com/davideast/inbrowser-agent) — David East сделал side project: запускает полноценный AI-пайплайн (включая инференс) внутри браузера. Никакого сервера — всё локально. Полезно для приватных данных или слабого интернета.

### CSS

- [Улучшаем карточки: кликабельная область через anchor positioning](https://thatemil.com/blog/clickable-surface-expansion-using-anchor-position/) — Эмиль Бьёрклунд показывает приём: накрываем карточку псевдоэлементом ссылки через position-area: center + place-self: stretch, а отступ снизу привязываем через anchor() ко вторичной кнопке. Никаких магических чисел.
- [Современное темизирование: light-dark(), contrast-color(), style-queries](https://una.im/modern-css-theming) — Una Kravets разбирает трёхкомпонентную систему CSS-темизирования: функции light-dark и contrast-color для prefers-color-scheme, плюс style-queries для стилизации по настройкам самого документа. Паттерны, которые работают прямо сейчас.
