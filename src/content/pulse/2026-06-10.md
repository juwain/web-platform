### Новости

- [WebKit в Safari 27 Beta (WWDC26)](https://webkit.org/blog/17967/news-from-wwdc26-webkit-in-safari-27-beta/) — Джен Симмонс представила 58 новых фич и 525 исправлений. Ключевое для веба: кастомизируемые <select>, anchor positioning с учётом трансформаций, новый CSS-псевдокласс :heading, значение `stretch` для размеров, revert-rule, top-level await в модулях, WebAssembly JSPI на visionOS через <model>. Значительный апдейт.

### Статьи, мнения, туториалы

#### JS/TS

- [Как React борется с проблемами VDOM-реконсиляции](https://t.me/kobezzza_channel/1206) — Разбор трёх эпох оптимизации React: ручная мемоизация (memo/shouldComponentUpdate), React Fiber (кооперативная многозадачность, ~20ms slices), и компилятор React 19 (автоматическая мемоизация JSX). Каждая эпоха решала проблему предыдущей, но не устранила корень — рендер всё равно вызывается на каждом апдейте.
- [Variadic Tuple Types в TypeScript: сила и ловушки](https://t.me/we_use_js/5316) — Продвинутые сигнатуры до variadic tuples были адом из overload'ов. Теперь `type Fn<T extends unknown[]> = (...args: [...T]) => void` работает. Redux middleware, router APIs, compose/curry utilities стали чище. Но комбинирование с infer, recursive и conditional types быстро превращает типовую систему в тёмный лес.

#### CSS

- [CSS-only UI: снижаем JS-нагрузку без боли](https://master.dev/blog/reduce-the-js-workload-with-no-or-lo-js-options/) — Chris Coyер собрал коллекцию примеров UI, которые раньше требовали JS, но теперь делаются чистыми CSS+HTML. Например табы через ::scroll-marker + anchor positioning. Современный подход — сначала проверить, можно ли сделать это без скриптов.
- [100 способов центрировать элемент (CSS-справочник)](https://css-generators.com/center/) — Исчерпывающий набор паттернов центрирования: grid place-items/grid-area, flexbox, absolute translate, fixed, container queries с cqi/cqb, position-relative и даже float-хаки. Каждый вариант с одним кликом копируется в буфер. Полезнее сохранить в закладки, чем запоминать все варианты.
