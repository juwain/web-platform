### CSS

- [Comparing Values With CSS progress()](https://blog.master.dev/comparing-values-with-css-progress/) — Новая функция CSS `progress()` отображает значение в диапазоне как 0–1. Подходит для адаптивных лэйаутов, типографики и даже boolean-подобной логики без JS — условно стилизуем элементы на основе `calc(progress(...) > 0.5)`.
