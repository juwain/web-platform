### Проекты

- [Prop For That](https://nerdy.dev/prop-for-that) — Декларативный способ пробросить данные из JS в CSS-переменные без ручного wiring. Подписался на `data-props-for`, получил живые значения прямо в style queries — viewport size, visibility, scroll velocity, цвета из картинки. Идеально для тех случаев, когда CSS ещё не умеет что-то получать, а писать костыли лень.

### Статьи, мнения, туториалы

#### JS/TS

- [AsyncLocalStorage в Node.js: паттерн для request-scoped контекста](https://t.me/we_use_js/5323) — Разбор реального production-паттерна: через `AsyncLocalStorage` пробрасываешь `requestId` и `traceId` через весь async-chain — middleware, базу, логи — без prop drilling. Автор честно пишет trade-offs: контекст не пересекает process boundaries, не заменяй аргументы функций бизнес-данными. Хороший гайд для тех, кто строит observability на Node.
- [Twoslash: формат разметки для TypeScript](https://github.com/twoslashes/twoslash) — Позволяет писать самодостаточные примеры кода в документации, где TypeScript-компилятор автоматически проверяет типы и генерирует ошибки прямо в разметке. Удобно для туториалов и статей, где важна воспроизводимость синтаксиса — компилятор сам следит, что примеры не ломаются при обновлении TS.
