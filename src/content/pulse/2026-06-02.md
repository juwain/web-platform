### Новости

- [Chrome 148 добавил <install> для PWA-установки прямо из страницы](https://developer.chrome.com/release-notes/148) — Новый HTML-элемент рендерит кнопку установки PWA на домашний экран. Браузер сам подставляет текст и содержимое — менять их нельзя, но стилизовать внешний вид можно. Генерирует три события: promptaction / promptdismiss / validationstatuschanged. Для сторонних PWA есть атрибут installurl. Таблица на caniuse пока не добавлена.

### Статьи, мнения, туториалы

#### CSS

- [Анимации появления и исчезновения с @starting-style и allow-discrete](https://joyofcode.xyz/entry-and-exit-css-transitions) — Мэтт Кроут разбирает трёхстадийную модель анимаций: on-the-way-in → open → on-the-way-out. @starting-style задаёт pre-animation state для :open-элементов, allow-discrete позволяет анимировать display и overlay (которые обычно меняются мгновенно), а View Transition API дополняет картину, анимируя изменения раскладки между состоями DOM — на примерах с <dialog> и поповерами. Работает во всех современных браузерах.
- [margin-trim: block — финальный ответ на margin-collapsing у контейнеров](https://t.me/trysound/120) — Свойство margin-trim: block автоматически отрезает вылезающие сверху/снизу отступы первого и последнего дочернего элемента внутри контейнера. Решает проблему «resets верхних margin у всех заголовков» раз и навсегда — нужно только дождаться поддержки в других движках, кроме Safari. Пока что fallback на CSS-утилиту через :first-child/:last-child работает отлично.
