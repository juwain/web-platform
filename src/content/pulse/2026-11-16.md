## Статьи, мнения, туториалы

### CSS

- [Creating Diagrams and Graphs Using Modern CSS](https://blog.master.dev/creating-diagrams-and-graphs-using-modern-css/?utm_source=CSS-Weekly&utm_campaign=Issue-640&utm_medium=web) — Temani Afif показывает, как строить диаграммы и графы на чистом CSS с помощью anchor positioning, `shape()`, `border-shape` и условий `if()`. Соединения между элементами адаптируются к их положению автоматически — демо можно перетаскивать. Пока Chrome-only, но отличный proof of concept возможностей современной платформы.
- [Playing with CSS Layers](https://kittygiraudel.com/2026/11/01/playing-with-css-layers/?utm_source=CSS-Weekly&utm_campaign=Issue-640&utm_medium=web) — Kitty Giraudel делится опытом использования CSS Layers на личном сайте: как `@layer` помогает управлять специфичностью и почему приходится оборачивать vendor-стили в `<style>@import url(...) layer(vendors)</style>`, пока `<link>` не поддерживает атрибут `layer`.
- [Visited links are purple](https://dbushell.com/2026/11/16/visited-links/) — David Bushell напоминает про `:visited` и возвращает фиолетовый цвет посещённым ссылкам. Отличный повод вспомнить, что Chromium уже с прошлого года использует link partitioning — стилизация `:visited` теперь безопаснее, чем кажется.
