## Новости

- [WebKit Features for Safari 27.2](https://webkit.org/blog/18515/webkit-features-for-safari-27-2/) — Safari 27.2 дорабатывает Customizable Select: теперь можно стилизовать выбранный текст через псевдоэлемент `::field-content`, не обязательно использовать `<selectedcontent>`. Grid Lanes обновлено — `flow-tolerance` переименовано в `fit-tolerance`, старое имя пока работает как deprecated alias. Также 20 багфиксов: Accessibility, WebGPU, WebRTC, Media, Forms и другое.
- [W3C launches second pilot of program to support Open Source projects](https://www.w3.org/blog/2026/w3c-launches-second-pilot-of-program-to-support-open-source-projects/) — W3C запустил второй пилот программы поддержки open source — полифилл для WebMCP, API который позволяет веб-приложениям экспонировать свои функции как «инструменты» для агентов и assistive-технологий. Пока спецификация в инкубации, полифилл даст разработчикам возможность экспериментировать. Также анонсирован Community Group для управления программой.

## Статьи, мнения, туториалы

### CSS

- [Useful @custom-media Presets](https://blog.master.dev/useful-custom-media-presets/) — Firefox 148 (за флагом `layout.css.custom-media.enabled`) получил поддержку `@custom-media` — CSS-переменных для медиазапросов. Автор собрал готовый набор пресетов под input-механизмы (mouse, touch, stylus, air, dpad), брейкпоинты (360–1560px с шагом 100px) и HDR, с fallback-вариантом на container style queries для текущих браузеров.

### Performance

- [Performance Budgets Need a Representative Worst](https://csswizardry.com/2026/10/web-perf-wednesday-014-performance-budgets-need-a-representative-worst/) — Гарри Робертс поправил свой подход к performance budgets: один аномальный замер (например, LCP скачет до 7.1 сек при обычных 2.2) может сделать бюджет бесполезным. Новый совет — брать репрезентативный худший случай, например P90 или P95 за период, и отдельно считать для синтетики и RUM. Бюджет должен ловить регрессии, а не просто проходить.
