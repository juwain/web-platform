### JS/TS

- [Типизация Strapi API через кодогенерацию](https://habr.com/ru/articles/1059984/?utm_campaign=1059984&utm_source=habrahabr&utm_medium=rss) — В Strapi формат ответа напрямую зависит от параметра populate — один эндпоинт возвращает кучу разных форм. Авторы разбирают, как выкрутиться через кодогенерацию: вытягиваешь схему с живого Strapi, генеряшь TypeScript-клиент и заставляешь систему типов вычислять тип ответа прямо из populate.

- [Mushroom Color Atlas](https://www.mushroomcoloratlas.com/) — Интерактивный атлас цветов, получаемых из разных видов грибов. Палитру можно фильтровать по грибу, типу ткани, протраве, красителю или пигменту. Для каждого цвета зафиксированы материалы и условия эксперимента.
