## Статьи, мнения, туториалы

### CSS

- [View Transitions: использовать attr() или match-element?](https://www.bram.us/2026/06/19/view-transition-name-attr-or-match-element/) — Bramus разбирает два подхода к задаче view-transition-name на практике. Kevin Powell показал attr(data-id type(<custom-ident>)) на CSS Day, но Cyd Stumpel спросил про match-element. Короткий ответ: да, сработает. Развёрнутый: match-element ограничен Same-Document переходами и не позволяет точно таргетить ::view-transition-*- псевдоэлементы. Для MPA и сложных анимаций attr() всё ещё король.
- [«Life is too short for lowercase ASCII»](https://dbushell.com/2026/06/19/css-methodology/) — Короткая заметка об авторской методологии CSS — вместо BEM и прочих строгих конвенций, классы компонентов пишутся PascalCase. `<article class="Post">`. Звучит безумно, но автор доводит мысль: современный CSS (`@scope`, `@container`, cascade layers, :where) делает жёсткие правила менее критичными. Конвенции стали проще — значит можно экспериментировать.
