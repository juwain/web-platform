## Статьи, мнения, туториалы

### CSS

- [Gap decorations стали стабильными в Chrome](https://developer.chrome.com/blog/gap-decorations-stable) — В Chrome стабилизировались CSS Gap Decorations: `row-rule` и `column-rule` для grid и flex позволяют рисовать разделители прямо между ячейками. Деградирует в Firefox и Safari безболезненно — просто не рисует линии. Хороший повод наконец избавиться от лишних обёрток вокруг каждой строки.
- [CSS text-fit — равняй текст по длине контейнера](https://t.me/frontend_pasta/845) — Свойство `text-fit` с значениями `shrink` и `grow` подошло к Chrome 150+. `shrink` уменьшает шрифт при переполнении, `grow` растягивает до размеров контейнера. Для адаптивных заголовков — находка, хотя остальные браузеры пока молчат.

### HTML/Accessibility

- [The Siren Song of ariaNotify()](https://master.dev/blog/the-siren-song-of-arianotify/) — Мэт Марквиз разбирает `ariaNotify()` из черновика WAI-ARIA 1.3 — метод, который позволяет программно заставить скринридер произнести строку напрямую, минуя танцы с `aria-live`. Удобно, но удобство оборачивается риском: спам уведомлениями вспомогательных технологий станет слишком простым. Будьте аккуратны.

### WebAssembly

- [Игры для старого Tizen TV на C++ и WebAssembly](https://t.me/htmlshit/4154) — Автор пишет аркады для старого Samsung TV на Tizen, компилируя C++ в NaCl и WebAssembly. Путь от 3 fps до стабильных 50 — с шейдерами и звуком. Главный инсайт: аудиоконтекст нужно держать прогретым, иначе всё падает вдвое. Классический case 'как выжать максимум из устаревшей платформы'.

### Инструменты

- [Как мы во фронтенд-команде ПСБ прокачали релизный цикл npm-пакетов](https://habr.com/ru/companies/psb/articles/1055888/) — Команда ПСБ рассказывает, как привела в порядок релизный цикл внутренних npm-пакетов: SemVer, обязательный migration guide для breaking changes и публикация только через CI. Результат — предсказуемые версии, никакого разъезда окружений и отсутствие человеческого фактора. Хороший рецепт для enterprise.
