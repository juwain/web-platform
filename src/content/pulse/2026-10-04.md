## Статьи, мнения, туториалы

### AI/Agents

- [webmcp-react](https://github.com/agentcathq/webmcp-react) — Обёртка для React-приложений, добавляющая поддержку WebMCP — позволяет AI-агентам напрямую обращаться к вашему сайту. Подход с приоритетом на Zod и безопасный в Strict Mode.

### CSS

- [Новые HTML и CSS фичи для дизайн-системы](https://zeroheight.com/blog/new-html-and-css-features-you-should-be-using-in-your-design-system/) — Подборка свежих веб-фич, которые уже можно применять в дизайн-системе: `sibling-index()` и `sibling-count()` (уже в трёх основных браузерах), `:has` в Web Platform Baseline, `@scope`, `@custom-media`, атрибут `popover` и `text-box-edge`/`text-box-trim`.

### Инструменты

- [MSW 3.0](https://mswjs.io/blog/introducing-msw-3.0) — Крупный релиз Mock Service Worker: теперь библиотека ESM-only, размер tarball уменьшился с 416KB до 234KB (-43%). Добавлены GraphQL-подписки, новый Network API и перехват сетевых запросов в Node.js на уровне сокетов — без патчинга request-клиентов.
